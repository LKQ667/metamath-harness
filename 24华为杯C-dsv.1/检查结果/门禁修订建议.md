## 二、与同源门禁的互斥

- `check_drawing_contract.py`（HTML 模式分支）：`invalid = [item for item in non_data if str(item.get("generator", "")).lower() != "html"]`，即非数据流程条目必须是 `html`。
- `check_roadmap_in_paper.py`：要求 manifest 中存在含「技术路线/路线图/roadmap/问题分析流程」字样的条目。
- 于是同一 manifest 条目被要求同时满足 `generator == "html"` 与 `generator ∈ {drawio, imagegen…}`，逻辑上无解；若删去关键词使该条目不存在，则 `check_roadmap_in_paper` 失败。
