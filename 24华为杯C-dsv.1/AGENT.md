# AGENT.md

## 项目规则

1. 禁止编造与禁止篡改数据、结果、文献与代码；严禁外推不存在的数值；所有数值必须来自 `results/final_results.json` 唯一结果源。
2. 严禁抄袭；引用外部结论必须标注来源并说明其在本文推导中的作用。
3. 数据来源必须逐条登记在 `data/source_map.md`，未登记来源的数据不得进入建模、图表或正文。
4. 全流程统一使用中文撰写正文、图题、图例、坐标轴与图内文字；代码关键字与专有名词除外。
5. 绘图与求解链路固定为：Python 数据图（matplotlib，导出 svg+pdf+png）+ HTML 矢量流程类图；概念类图只保留 `手绘图/*.md` 提示词。
6. 柱状图策略为「禁用」：源码中不得出现柱形 API；时间区间一律用线段与端点标记表达。
7. 每个非空 Q 目录必须保留本问主脚本、模型说明与结果文件，禁止把代码链路全部集中在 `scripts/`。
8. 阶段推进必须以门禁退出码为准；门禁失败时先完整读取 `failures_summary.json`，同回合内修复全部失败项后重跑。
9. 真实业务代码不得为附录展示而改写；附录代码使用 `scripts/prepare_appendix_code.py` 生成等价净化副本并完成运行回归。
