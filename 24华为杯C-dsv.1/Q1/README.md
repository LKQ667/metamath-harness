# 问题一：确定性条件下 2024—2030 年最优种植方案

## 目标

在预期销售量、种植成本、亩产量与销售价格相对 2023 年保持稳定的前提下，给出 2024—2030 年逐地块、逐季次、逐作物的种植面积安排，使七年总利润最大；分别处理"超产滞销"与"超产按 2023 年价格 50% 出售"两种处置规则。

## 输入

- `赛题/附件1.xlsx`：54 个地块的名称、类型、面积与季次容量；41 种作物的类型与可种空间。
- `赛题/附件2.xlsx`：逐（作物, 地块类型, 季次）的亩产量、种植成本与销售价格区间；2023 年逐地块种植面积。
- 派生表：`data/派生/plots.csv`、`crops.csv`、`params.csv`、`base2023.csv`、`demand2023.csv`。

## 核心假设

1. 远期预期销售量沿用 2023 年实际总产量作为上限，销售价格取附件 2 区间的中点作为名义价格。
2. 同一作物在同一地块的同一年内不重复种植；不同地块之间可以重复种植同一作物。
3. 同一地块相邻两年不种植同一作物；豆类三年窗口以面积之和为正表示轮作到位。
4. 地块内单次落位面积不低于 0.3 亩；同一年同一作物的落位地块数不超过 10 个。
5. 水浇地每年至少一季投入生产，两季合计不超过地块面积；第二季晚季蔬菜（大白菜、白萝卜、红萝卜）至多选一种。

## 方法

候选方法有三类：逐地块贪心分配、以作物为单位的线性规划、以地块-作物-季次-年份为决策单元的混合整数线性规划。贪心分配无法同时满足轮作窗口与集中管理，线性规划无法表达落位与轮作 0-1 逻辑，因此选定第三类。

**决策变量**：$x_{p,c,s,t}\ge 0$ 为地块 $p$ 第 $t$ 年季次 $s$ 上作物 $c$ 的种植面积；$y_{p,c,s,t}$、$u_{p,c,t}$、$d_{p,c,t}$ 为落位、单年落位与地块占用的 0-1 变量；$q_{c,t}$ 为正常销售量，$r_{c,t}$ 为销售收益。

**目标函数**：

$$\max \sum_{t}\Big(\sum_{c} r_{c,t}-\sum_{p,c,s} C_{c,k(p)}x_{p,c,s,t}\Big)$$

其中收益按处置规则取分段上界：情形一 $r_{c,t}\le P_c q_{c,t}$ 且 $q_{c,t}\le D_c$；情形二在此基础上允许超出部分按 $0.5P_c$ 计入。

**约束条件**：季次容量 $\sum_{c}x_{p,c,s,t}\le A_p$；水浇地两季合计不超过 $A_p$；相邻年不重茬 $d_{p,c,t}+d_{p,c,t-1}\le 1$；豆类窗口 $\sum_{t'=t}^{t+2}\sum_{c\in B}x_{p,c,s,t'}\ge 0.1$；最小落位面积 $x_{p,c,s,t}\ge 0.3y_{p,c,s,t}$；单年落位地块数 $\sum_{p}u_{p,c,t}\le 10$。

**公式与变量**：面积变量 $x_{p,c,s,t}$、落位变量 $y_{p,c,s,t}$、轮作变量 $d_{p,c,t}$；目标函数 $\max\sum_t(\sum_c r_{c,t}-\sum C_{c,k}x)$；超产定义式 $e_{c,t}\ge \pi_{c,t}-D_c$。

**求解**：CBC 分支定界，间隙上限 1%，单次时限 600 秒。

## 验证

求解后对四类结构性约束逐项回检：重茬次数、豆类三年窗口失败地块数、地块容量越界次数、低于最小落位面积的记录数；同时核对总产量与销售量的口径一致性。
