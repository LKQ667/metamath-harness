# 问题二：参数不确定与种植风险下的稳健种植方案

## 目标

在预期销售量、亩产量、种植成本与销售价格随年份变化且存在不确定性的条件下，给出 2024—2030 年最优种植方案，并在收益与种植风险之间给出可选择的权衡方案。

## 输入

- 问题一的全部派生表。
- 题目给出的变化趋势：小麦与玉米预期销售量年增长 5%—10%；其他作物销量相对 2023 年约 ±5%；亩产量年变化 ±10%；种植成本年均增长约 5%；粮食类价格基本稳定；蔬菜价格年均增长约 5%；食用菌价格年均下降 1%—5%，羊肚菌每年下降 5%。

## 核心假设

1. 将题目给出的区间端点与中值组合为 8 个代表性情景，情景等概率，用于刻画参数漂移的联合影响。
2. 情景内各参数按年际乘子作用在名义亩产量、种植成本、销售价格与预期销售量上，模型结构不变。
3. 不确定性的风险用年度收益分布的尾部平均损失（CVaR，$\alpha=0.9$）度量，风险厌恶系数 $\lambda$ 作为权衡参数。
4. 超产部分按 2023 年价格的 50% 计价，超出部分不计入正常销售上限。

## 方法

方法比较：确定性等价模型（用期望系数求解）计算量最小但忽略尾部风险；机会约束模型需要分布假设且不易在混合整数框架下求解；情景型随机规划加均值-CVaR 目标既保留混合整数结构，又能直接输出风险-收益前沿，故选定第三类。

**目标函数**：$\max\ \mathbb{E}[\Pi]-\lambda\,\mathrm{CVaR}_{\alpha}$，其中

$$\mathbb{E}[\Pi]=\sum_{t}w_t\Pi_t,\qquad \mathrm{CVaR}_{\alpha}=\min_{\eta}\Big\{\eta+\frac{1}{1-\alpha}\sum_{t}w_t\max(0,\eta-\Pi_t)\Big\}$$

线性化后引入辅助变量 $\eta$ 与 $u_t\ge 0$，约束为 $u_t\ge \eta-\Pi_t$。

**参数与情景**：成本乘子 $(1.05)^{t}$，产量乘子 $1\pm0.10$，蔬菜价格乘子 $(1.05)^t$，食用菌价格乘子 $(1-\delta)^t$，粮食需求乘子 $(1+g)^t$，其中 $g\in[0.05,0.10]$、$\delta\in[0.01,0.05]$。

**公式**：目标 $\max\ \mathbb{E}[\Pi]-\lambda\mathrm{CVaR}_{\alpha}$；风险项 $\mathrm{CVaR}_{\alpha}=\min_{\eta}\{\eta+\frac{1}{1-\alpha}\sum_t w_t\mu_t\}$；情景系数 $\tilde{Y}=Y\kappa^Y$。

**求解步骤**：先对 8 个情景分别独立求解得到情景最优利润分布，再在期望系数上以 $\lambda\in\{0,1,3\}$ 求解得到前沿，最后用 8 个情景对每个方案做滚动评估。

## 验证

- 结构审计：重茬、豆类窗口、地块容量、最小落位面积全部回检。
- 一致性检验：情景独立最优利润与均值-CVaR 方案的评估利润对比，确定性等价解与随机解的价值差（VSS）作为信息价值度量。
- 前沿单调性：随 $\lambda$ 增大，利润均值下降、尾部收益上升。
