# 问题三：作物替代互补与量价相关下的种植策略及与问题二对比

## 目标

在问题二基础上进一步考虑作物之间的替代性与互补性，以及预期销售量、销售价格与种植成本之间的相关性，给出 2024—2030 年最优种植策略，并通过模拟数据求解，与问题二结果作比较分析。

## 输入

- 问题一、问题二的全部派生表与情景框架。
- 题目给出的替代互补与相关性定性描述：同类作物之间以替代关系为主，蔬菜与食用菌之间以互补关系为主，价格随供给量上升而下降，成本随种植规模上升而上升。

## 核心假设

1. 作物按粮食、豆类、蔬菜、食用菌分为四组，组内替代、组间互补，用组间相关系数矩阵刻画情形相关系数。
2. 组内冲击同向作用于该组所有作物的价格与销量乘子，叠加作物层面的独立冲击；相关系数矩阵取对称正定矩阵并通过 Cholesky 分解生成多元正态情景。
3. 销售量与销售价格之间存在负相关：销量占预期销售量比例越高，实际成交价相对名义价的下调幅度越大，下调强度按作物组的弹性系数取值。
4. 保留问题二的超产处置规则与全部结构性约束。

## 方法

方法比较：直接对价格与销量建立显式需求函数会把线性规划变成非线性规划，规模不可控；只对期望系数做单点修正无法体现相关性；采用"相关情景生成 + 均值-CVaR 规划 + 事后弹性定价评估"的三段式链路，既保持混合整数线性结构，又能定量给出替代互补与相关性的影响，故选定第三段链路。

**决策变量与公式**：沿用问题一的面积变量 $x_{p,c,s,t}$ 与落位变量 $y_{p,c,s,t}$；目标 $\max\ \mathbb{E}[\Pi]-\lambda\mathrm{CVaR}_{\alpha}$；弹性定价 $P^{\text{eff}}_c=P_c(1-\beta_g q_c/D_c)$。

**相关情景生成**：设 $Z\sim N(0,\Sigma)$，$\Sigma$ 为四组相关系数矩阵，经 Cholesky 分解 $\Sigma=LL^{\top}$ 得到 $Z=L\xi$，$\xi\sim N(0,I)$；组冲击 $z_g$ 与作物独立冲击 $\epsilon_c$ 共同决定价格与销量乘子。

**弹性定价**：对作物 $c$ 的成交价按 $P_c^{\text{eff}}=P_c\big(1-\beta_g\, q_c/D_c\big)$ 修正，$\beta_g$ 为所属组的弹性系数，$q_c$ 为销量，$D_c$ 为预期销售量。

**目标函数**：与问题二同为 $\max\ \mathbb{E}[\Pi]-\lambda\,\mathrm{CVaR}_{\alpha}$，$\lambda\in\{0,1,3\}$。

## 验证

- 与问题二同口径的结构审计与情景评估。
- 相关性显著性：比较含弹性与不含弹性两种口径下的利润均值差，量化量价相关带来的收益变化。
- 稳定性对比：计算问题三方案与问题二方案的情景标准差之比，检验相关性纳入后风险是否下降。
