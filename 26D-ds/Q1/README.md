# 问题一：单点往返运输能力与货箱组批方案

## 目标

在不考虑实体无人机与共享电池调度的前提下，研究单服务区直接往返 O01→Si→O01 的运输能力与货箱组批：

1. 计算三种机型在 15 个服务区执行单点往返任务时的最大安全载荷；
2. 在货箱不可拆、每箱只安排一次、不跨服务区组批，且满足载质量、装载体积与返航安全能量余量的条件下，
   确定各服务区的货箱组批方案；
3. 以往返架次数、总运输能耗、累计作业时间为指标优化组批方案，说明指标间的权衡关系；
4. 讨论返航安全余量变化对最大安全载荷与组批结果的影响。

## 输入

- `data/derived/nodes.csv`：16 个节点的经纬度、附件海拔、作业高度；
- `data/derived/boxes.csv`：80 个货箱的服务区、物资类型、质量、体积、首批保障属性；
- `data/derived/segment_geometry.csv`：240 条有向航段的水平距离、计划巡航海拔、爬升与下降高度；
- 机型参数：A/B/C 三型的空载与满载标准航程、最大载货质量、可用装载体积、电池可用能量、
  返航电量下限、爬升与下降速度、爬升能耗效率、准备与交接时间。

## 假设

1. 同一服务区内、同一物资类型、同一首批保障属性的货箱在质量与体积上完全同质，可视为同类物品；
2. 每个架次只服务一个服务区，去程载该架次的全部货箱、回程空载；
3. 下降阶段不单独计算附加能耗（题目给定下降能耗效率为 0）；
4. 架次作业时间由工位固定准备时间、逐箱装载时间、往返飞行时间与接收点交接时间构成；
5. 单点往返不涉及实体无人机与电池的数量与周转限制，故累计作业时间按各架次作业时间求和计算。

## 变量

| 符号 | 含义 | 单位 |
|---|---|---|
| $g$ | 运输机型，$g\in\{A,B,C\}$ | — |
| $i$ | 服务区编号，$i\in\{S001,\dots,S015\}$ | — |
| $q$ | 架次有效载荷 | kg |
| $L_g(q)$ | 机型 $g$ 携带载荷 $q$ 时的等效航程 | m |
| $Q_g$ | 机型 $g$ 的最大载货质量 | kg |
| $\rho_g$ | 机型 $g$ 的返航安全余量比例 | — |
| $E_g^{use}$ | 机型 $g$ 单组电池的可用能量 | kWh |
| $q^{*}_{g,i}$ | 机型 $g$ 在服务区 $i$ 的最大安全载荷 | kg |
| $d_{ij}$ | 节点 $i$ 到 $j$ 的水平巡航距离 | m |
| $h^{+}_{ij},h^{-}_{ij}$ | 航段爬升高度与下降高度 | m |
| $E^{T}_{p}$ | 架次 $p$ 的总运输能耗 | kWh |
| $N,E,T$ | 总架次数、总运输能耗、累计作业时间 | 架次、kWh、s |

## 公式

**等效航程**（题目附录 2）：

$$L_g(q)=L_g^{0}-\left(L_g^{0}-L_g^{F}\right)\left(\frac{q}{Q_g}\right)^{3/2},\qquad 0\le q\le Q_g .$$

**航段飞行时间**：

$$t^{g}_{ij}=\frac{h^{+}_{ij}}{v^{\uparrow}_{g}}+\frac{d_{ij}}{v^{c}_{g}}+\frac{h^{-}_{ij}}{v^{\downarrow}_{g}} .$$

**航段能耗**（水平巡航能耗 + 爬升附加能耗）：

$$E^{g}_{ij}(q)=\underbrace{E^{use}_{g}\cdot\frac{d_{ij}}{L_g(q)}}_{\text{水平巡航}}+\underbrace{\frac{(m_g+q)\,g\,h^{+}_{ij}}{3.6\times10^{6}\,\eta^{\uparrow}_{g}}}_{\text{爬升附加}} .$$

**单点往返能耗**：去程载 $q$、回程空载，故

$$E^{rt}_{g,i}(q)=E^{g}_{O01,i}(q)+E^{g}_{i,O01}(0).$$

**最大安全载荷**：在返航安全余量约束下取最大可行载荷

$$q^{*}_{g,i}=\max\left\{q\in[0,Q_g]\;\middle|\;E^{rt}_{g,i}(q)\le\left(1-\rho_g\right)E^{use}_{g}\right\}.$$

由于 $L_g(q)$ 关于 $q$ 单调递减、爬升项关于 $q$ 单调递增，$E^{rt}_{g,i}(q)$ 关于 $q$ 严格单调递增，
故约束的左端是 $q$ 的单调函数，$q^{*}_{g,i}$ 可由二分法唯一确定。

**架次作业时间**：

$$\tau_{g,i}(n)=\tau^{prep}_{g}+n\,\tau^{load}_{g}+t^{g}_{O01,i}+t^{g}_{i,O01}
+\tau^{hand}_{g,0}+n\,\tau^{hand}_{g,1}.$$

## 约束

对每个服务区 $i$ 的货箱集合 $\mathcal{B}_i$ 的划分 $\{P_1,\dots,P_N\}$ 与机型指派 $g(p)$：

$$\sum_{b\in P_p} m_b\le q^{*}_{g(p),i},\qquad
\sum_{b\in P_p} v_b\le V_{g(p)},\qquad
E^{rt}_{g(p),i}\Big(\sum_{b\in P_p} m_b\Big)\le\left(1-\rho_{g(p)}\right)E^{use}_{g(p)} .$$

并满足货箱不可拆（每个 $b$ 恰好属于一个 $P_p$）与不跨服务区组批（$P_p\subseteq\mathcal{B}_i$）。

## 方法

1. **最大安全载荷**：对 3 机型 × 15 服务区共 45 个组合分别用二分法求 $q^{*}_{g,i}$，
   二分区间 $[0,Q_g]$，收敛容差 $10^{-5}$ kg。
2. **组批优化**：同一服务区内同类物品可互换，故以"各类物品剩余数量向量"为状态、
   以（机型，各类物品取用数量向量）为动作，做精确动态规划（规范元 + 状态压缩），
   得到该服务区的全局最优划分，避免枚举 $2^{|\mathcal{B}_i|}$ 个货箱子集。
3. **三指标权衡**：分别以字典序 $N\to E\to T$、$E\to N\to T$、$T\to N\to E$ 求解，
   再在"恰好使用 $N$ 个架次"的约束下逐层求最小能耗，得到完整的 $(N,E,T)$ 前沿，
   并按支配关系提取真实 Pareto 集。
4. **灵敏度**：$\rho$ 在 $0.10$ 至 $0.40$ 内以 $0.01$ 步长扫描，
   并对"全部货箱可投递"的可行性做二分，求临界返航安全余量 $\rho_{c}$。

## 验证

1. **单调性与边界核对**：$E^{rt}_{g,i}(q)$ 在 $q\in[0,Q_g]$ 上单调递增，
   二分结果满足 $E^{rt}(q^{*})\le(1-\rho)E^{use}<E^{rt}(q^{*}+\delta)$；
2. **容量上界核对**：所有 $q^{*}_{g,i}\le Q_g$，且 $q^{*}_{g,i}>0$；
3. **可行性核对**：最优组批方案中每个架次的载质量不超过 $q^{*}$、装载体积不超过 $V_g$；
4. **最优性核对**：动态规划以"最低未覆盖物品"为规范元，状态空间覆盖全部可达剩余向量，
   故所得解为精确最优而非启发式近似；
5. **规模核对**：交付的 80 个货箱全部被安排且仅被安排一次，各服务区箱数与需求表一致；
6. **临界值核对**：$\rho$ 超过 $\rho_c$ 后逐区核对不可投递的原因是该区最重货箱超出所有机型安全载荷。
