## 画面描述

画面主体是一条从左到右的水平时间轴，轴上均匀标出 5 个时刻刻度，刻度下方分别
写「t₁」到「t₅」。时间轴上方是三条平行的泳道。

第一条泳道标注「核 0 的 COPY_IN」，在 t₁ 与 t₄ 各画一个小方块，方块内写
「张量 A」与「张量 C」。

第二条泳道标注「核 1 的 COPY_IN」，在 t₂ 与 t₅ 各画一个小方块，分别写
「张量 A」与「张量 C」。

第三条泳道标注「只读 L2（1 MB，FIFO）」，在 t₁ 与 t₂ 之间画一个宽矩形表示
张量 A 的驻留区间，在 t₄ 与 t₅ 之间画另一个宽矩形表示张量 C 的驻留区间；
从第一条泳道的张量 A 方块向下引实线箭头进入 L2 矩形，标注「未命中→写回」；
从第二条泳道的张量 A 方块向下引虚线箭头指向 L2 矩形，标注「命中，带宽 250 B/cycle」。
在 t₃ 处从 L2 矩形右侧引出一条向下的短箭头，标注「FIFO 淘汰」，落到一条
标注「DDR 60 B/cycle」的横条上，表示 L2 与 DDR 两条带宽池互不占用。
