# 文献阅读笔记

本文件记录与赛题直接相关文献的阅读要点，以及它们各自支撑本文哪一部分建模或算法。
所有条目均给出可核验来源，正文引用时按 `thebibliography` 中的键名对应。

## R1 HEFT 列表调度

- 核心结论：在异构处理器上，按任务的后向关键路径长度（upward rank）排序，并把每个
  任务分配到使其最早完成时间最小的处理器，可以得到质量稳定、复杂度为 O(v^2·p) 的调度。
- 本文用途：子图分核阶段采用同一优先级准则。差别在于赛题的调度单元是子图而不是操作，
  且同一核心上连续执行两个子图需要支付固定等待，因此插入代价函数中加入同核换任务等待项。
- 适用条件：任务执行时间已知且静态；跨核通信代价与数据量无关（本题跨核等待为固定周期数，
  与该前提一致）。

## R2 mNPUsim

- 核心结论：多核 NPU 共享 DRAM 时，带宽在核间按并发请求公平分摊，静态划分带宽与动态共享
  在吞吐与公平性上表现不同；片上缓存复用是缓解带宽压力的主要手段。
- 本文用途：支撑“共享 DDR 带宽争用”的建模假设，并解释为什么切图要尽量减少边界张量，
  以及为什么问题三的只读 Cache 能把重复读取从 DDR 流量中剥离。

## R3 多级图划分

- 核心结论：最小割图划分是 NP 难问题，多级粗化—初始划分—细化可在近线性时间内给出高质量划分。
- 本文用途：说明切图环节与经典图划分同源，但本题目标不是最小割，而是任务级完工时间，
  且必须保证子图依赖图无环，因此不能直接套用最小割划分，需要面向无环性重新构造切分。

## R4 DAG 调度综述

- 核心结论：DAG 调度方法可分为列表调度、聚簇调度、基于复制的调度与元启发式四大类；
  聚簇调度天然同时决定“分组”与“分核”，与本题“切图 + 分核 + 核内排序”的三段结构最贴近。
- 本文用途：候选方法比选的依据。本文最终选择“保持后代连续的拓扑序 + 连续段切分 + 列表调度”，
  属于聚簇调度家族，并额外显式保证商图无环。

## R5、R6 官方算法说明

- 核心结论：核内调度为确定性启发式，容量不足时自动插入缓存换出与换入；多核模拟按事件驱动
  推进，DDR 与只读 Cache 各自独立结算带宽。
- 本文用途：估算模型的依据。子图时长上界取四条流水线工作量与核内关键路径的最大值，
  边界搬运量按张量字节数折算周期，与官方口径保持一致。
