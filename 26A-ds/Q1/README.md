# 问题一（场景 A）建模说明

## 目标

在无核间同步机制的场景 A 下，为每个核内操作分配子图 id，并把子图分配到 2～5 个
核心、确定每个核心上的子图执行顺序，使总体任务执行时间（Makespan）尽可能短，
同时控制总额外数据搬运量。

## 输入

- 计算图 `case_*.json`：Op-Tensor 二部图，`ops` 含 `op`、`pipe`、`cycles`，
  `tensors` 含 `pos`、`size`。
- 固定配置：L1 = 524288 字节，UB = 131072 字节，DDR 带宽 = 60 字节/周期，
  跨核前驱等待 = 1000 周期，同核 Task 切换等待 = 100 周期。
- 场景 A 规则：每个子图独立构成一个 Task；所有跨子图数据必须经 DDR 中转，
  即使两个子图位于同一核心。

## 核心假设

1. 同构核心：N 个核心的计算能力与缓存容量完全相同，因此负载均衡只取决于分配
   到各核的工作量。
2. 静态调度：全部决策在执行前一次性确定，运行期不重调度。
3. 子图内四条流水线并行、同流水线串行；子图时长下界为各流水线工作量与核内
   关键路径的最大值。
4. 边界搬运量按张量字节数计，DDR 带宽在全部核之间公平分摊。
5. 子图依赖图必须无环，否则方案判为无效。

## 变量

| 符号 | 含义 |
|---|---|
| $V$ | 核内操作集合（非 COPY 操作） |
| $E$ | 操作级依赖边集合（由二部图收缩得到） |
| $N$ | 核心数 |
| $w_v$ | 操作 $v$ 的周期数，$w^M_v$、$w^V_v$ 分别对应 PIPE_M 与 PIPE_V |
| $\sigma$ | 拓扑序（序列），$\sigma(i)$ 为第 $i$ 个操作 |
| $b_0 < b_1 < \cdots < b_N$ | 切点边界，第 $k$ 个连续段为 $\sigma[b_{k-1}:b_k]$ |
| $G_k$ | 第 $k$ 个子图（连续段）的操作集合 |
| $D_k$ | 子图 $k$ 的估算时长 |
| $c_k$ | 子图 $k$ 分配到的核心 |
| $t_k$ | 子图 $k$ 的估算开始时刻 |

## 模型与公式

**切分决策。** 选一个拓扑序 $\sigma$ 与切点边界，使每个子图是 $\sigma$ 上的连续段。
连续段之间的依赖边必然沿 $\sigma$ 正向，因此商图（子图依赖图）天然无环，从构造上
满足赛题的合法性硬约束。

**切点代价。** 在位置 $p$ 处切开时，跨切边数为

$$X(p) = \bigl|\{(u,v)\in E : \mathrm{pos}(u) < p \le \mathrm{pos}(v)\}\bigr|$$

负载偏差为 $|W(b_{k-1},p) - \bar W| / \bar W$，其中 $W$ 为段内总周期数，$\bar W$
为平均段工作量。切点按

$$\mathrm{cost}(p) = X(p) + 3\cdot\frac{\bigl|W(b_{k-1},p)-\bar W\bigr|}{\bar W}$$

取最小者，得到初始切分。

**子图时长估算。** 记段 $k$ 的矩阵流水线工作量 $M_k$、向量流水线工作量 $V_k$、
入向边界字节 $B^{\mathrm{in}}_k$、出向边界字节 $B^{\mathrm{out}}_k$，则

$$D_k=\max\Bigl(M_k,\;V_k,\;\frac{B^{\mathrm{in}}_k}{\mathrm{BW}},\;\frac{B^{\mathrm{out}}_k}{\mathrm{BW}}\Bigr)$$

**分核决策。** 用 HEFT 式列表调度：按子图的后向关键路径长度

$$\mathrm{rank}(k)=D_k+\max_{k\to j}\mathrm{rank}(j)$$

降序处理，把子图 $k$ 分配到使估算完成时刻最小的核心：

$$t_k=\max\Bigl(\text{核空闲时刻},\ \max_{i\to k}\bigl(t_i+D_i+\Delta(c_i,c_k)\bigr)\Bigr)$$

其中 $\Delta(c_i,c_k)$ 在同核取 100（同核换 Task 等待）、跨核取 1000（跨核前驱等待）。

**局部搜索。** 以估算完工时间 $\max_k (t_k+D_k)$ 为目标，对每个切点在其邻域窗口内
做坐标下降；只有目标下降才接受新切点，否则回退。该回环保证切分与分核在同一目标
函数下联合改进。

## 约束

1. 每个核内操作必须且只能属于一个子图；
2. 每个子图必须且只能被调度一次；
3. 同核子图顺序不得违反子图依赖；
4. 子图依赖图必须无环；
5. 子图内部受 L1/UB 容量约束，容量不足时由官方核内调度器插入缓存换出换入。

## 方法

主方法为「保持后代连续的拓扑序 + 连续段切分 + HEFT 分核 + 切点坐标下降」。
候选方法比较见 `result.md`。

## 验证设计

1. 全部 100 个用例、1～5 核配置下调用赛题官方评估程序，记录 Makespan 与额外
   搬运量；
2. 与单核基线比较得到加速比，检查 2～5 核的加速比是否随核数单调不减；
3. 用估算完工时间与实际 Makespan 的相关性检查估算模型是否可用作搜索目标；
4. 对本质串行用例单独核对加速比是否接近 1，确认算法不会造成劣化。
