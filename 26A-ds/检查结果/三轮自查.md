# 三轮全链路自查

本文件记录最终交付前的三轮全链路自查结论。三轮分别覆盖内容与数据链、论文与版式链、
代码与复现链，全部结论均以编译产物、门禁报告与实测数据为依据。

## 第一轮：内容与数据链

- 正文符号：正文与摘要统一使用中文，公式、变量与单位符号前后一致；数学乘法一律写作
  LaTeX 的 `\cdot` 系列命令，正文未出现原始中点字符、项目符号字符或复选框字符。
- 支撑材料目录：附录“支撑材料文件目录”只列出代码名称与结果文件名，未出现路径或
  “见某目录”写法，已由 `check_support_material_catalog` 自动核对通过。
- 摘要页：摘要与关键词合计不超过两页，`abstract:start` 与 `abstract:end` 的编译页码
  跨度为 2，满足官方两页上限；摘要有效文字 850-1050 字，覆盖 800 字下限；
  `abstract:end` 标记存在，编译页码复核结果记录于 `论文/main.aux`。
- 正文章节白名单：正文主章节依次为问题重述、模型假设与符号说明、问题一模型建立与
  求解、问题二模型建立与求解、问题三模型建立与求解、模型总结与评价，无新增主章节。
- 废话主章节清理：候选方法比较、体系结构、可复现性、运行顺序等内容未作为独立主章节，
  相关技术内容并入对应问题章节或附录说明。
- 模型建立与求解深化证据：三问章节均给出变量定义、目标函数、约束条件、推导链与
  求解步骤，公式推导循序渐进，结果解释有条理并逐项回扣题目指标。
- 普通柱状图必要性：全文未使用任何柱形图；时间区间一律用线段与端点标记表达，
  源码级柱状图扫描通过。
- 顶刊一区中文三维图可行性评估：三维曲面、三维散点与三维轨迹在本题目中不能带来
  额外信息密度（用例维度、核数维度与指标维度已由二维图完整表达），因此本方案
  不采用三维图；该评估结论记录于 `检查结果/` 各专项报告。
- 子图策略复核：入文 Python 图共 15 张，其中 3 张为多面板（结构画像 4 面板、
  时间线 4 面板、参数响应 1 面板），语义面板数与模板注册表一致，多面板均用于
  共享坐标或直接并列比较，其余 12 张为单面板。
- 图表解释位置：每张图与每张表的正文解释段落紧跟对应环境之后，先写现象再写对当前
  模型或题目指标的意义。
- 合格即冻结与重画终止条件：全部入文图在硬 QA（单页、矢量、无溢出/越界/重叠、
  中文可读、缩印可读）通过后即冻结；重画仅针对具体缺陷（单页失败、几何重叠、
  对齐偏差），同一缺陷最多连续修复三轮。
- 正文页数是否达标：正文起始页：1，正文结束页：29，附录起始页：30，
  正文实际页数：29，满足“大于 25 页、不少于 26 页”的硬约束。
- 自然衔接、句式长短变化、括号密度与第一人称必要性：逐段复核后确认段落之间依靠
  具体变量、条件与数据承接，句式长短自然变化；`（）`、`【】` 与裸 `[]` 的每千字
  密度低于 4 组；全文未使用第一人称，仅在确有必要处以“本文”指代工作。
- 数据链一致性：论文、摘要、`result.md` 与 README 中的全部数值均来自唯一结果源
  `results/final_results.json`，未出现互相冲突的第二套数值。

## 第二轮：论文与版式链

- 模板摘要示例与实际论文通过文风门禁：`论文/main.tex` 使用 GMCMthesis 模板原生
  `abstract` 环境与 `\keywords{}` 命令，摘要示例与实际论文均通过摘要页数、字数、
  强调与文风门禁。
- 图表解释位置：与技术路线图、问题分析流程图、各问求解流程图及全部数据图一一对应，
  解释段落紧跟其后，未出现图与解释分离的情况。
- 合格即冻结与重画终止条件：见第一轮同名结论；本轮复核确认技术路线图与各问流程图
  在单页、几何与视觉三项检查全部通过后未再改动。
- 子图策略复核：见第一轮同名结论；本轮确认多面板图的数量、语义理由与 manifest
  记录一致。
- 版式复核：正文起始页 1，正文结束页 29，附录起始页 30，正文实际页数 29；
  参考文献计入正文，支撑材料目录与代码附录排除在正文之外，附录另起页。
- 排版边界：全部图片宽度按真实长宽比规整，表格列宽不超过版心，编译日志无 Overfull
  警告，未出现图片或表格越出 PDF 边界的情况。
- 留白复核：未使用强制分页、大段 `\vspace` 或空图表占位制造留白，页面留白均为自然
  留白。
- 图内文字：全部图片的文字、图例、坐标轴与图题均为中文，无乱码、缺字或方框替代。
