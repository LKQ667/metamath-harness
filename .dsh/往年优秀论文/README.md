# 内置优秀论文库

本目录随 MetaMath Harness 源码和发行包一起分发，供论文生成与评审 Skill 在用户开启“参考优秀论文完成度”后按赛事、题号和年份选择样本。

## 目录与清单

- 唯一论文库位置：`<DSH_HOME>/往年优秀论文/`。
- 赛事使用 `catalog.json` 中的规范名；目录下可以继续按年份和题号分层。
- 文件名保留原名，检索以 `catalog.json` 的元数据为准，不从文件名猜测未知年份。
- `catalog.json` 每条记录包含相对路径、赛事、年份、题号、优先级和 SHA-256。

## 使用规则

- Skill 只读取统一发现脚本返回的样本，不会一次读取整个目录。
- 已知题号时只选同题样本；找不到时记录“暂无匹配样本”并继续执行。
- 官方规则和当届赛题始终优先，样本只用于校准完成度、章节深度、论证链和图表密度。
- 不直接复制样本的文字、公式、图表、数据或结论。

## 维护

新增、替换或删除 PDF 后，运行：

```powershell
python .dsh/skills/_shared/scripts/discover_excellent_papers.py --dsh-home .dsh --verify-all
```

只有清单中全部路径、文件类型和 SHA-256 通过后才能制作发行包。统一论文库会增加源码与发行包下载体积。
