# 顶刊风格蒸馏规则

本文件只保留从 `py-nature` 中抽取、且与“提示词生成”直接相关的精华规则，不复制 Python 实现层。

## 1. 配色不是装饰，是语义

- 主方法、主对象：深蓝或稳重蓝系
- 基线、背景结构：中性灰或浅灰
- 上升、改进、有效机制：克制绿色，只在需要时点到为止
- 风险、劣化、抑制：克制红色，只做方向性提示
- 强调点：橙或金，仅局部一次

禁忌：

- 不用高饱和彩虹色
- 不让同一语义在不同图里随意换色
- 不用大面积紫蓝霓虹感

## 2. 布局先分层，再谈美观

顶刊级机制图优先遵循信息层次：

- hero 层：一眼交代对象、结构或主要机制
- support 层：补充流程、局部关系、关键差异、时序或空间逻辑

常用范式：

- 上方主图 + 下方 2–3 个支撑块
- 左侧主结构 + 右侧机制链
- 空间主图 + 网络结构图 + 指标摘要块

规则：

- 每张图只承担一个核心叙事任务
- 多 panel 时，信息层级必须清楚
- 复杂图例优先独立区域，不压在主图上

## 3. 顶刊论文感来自克制

- 白底优先
- 背景干净
- 边框、阴影、纹理、渐变谨慎使用
- 除主对象和关键路径外，不做花哨装饰
- 文字少而准，不把图做成说明书

## 4. 避免 AI 海报味

以下特征默认避免：

- 发光、镜面、高反射、未来科幻 UI
- 过密的小图标拼贴
- 大面积炫光、粒子、烟雾、景深噪点
- 营销海报式 slogan
- 情绪化夸张颜色和中心爆炸构图

## 5. 叙事顺序必须像论文，不像广告

默认按以下顺序组织图像语言：

1. 对象或系统
2. 结构或模块
3. 作用关系
4. 关键路径或反馈
5. 局部差异或支撑信息

不要一上来就追求“视觉冲击”，先保证科学关系可读。

## 6. 同组图片的协同规则

- 同组图共享一套语义配色
- 同一符号、箭头、色块在不同图中保持一致含义
- 不同图分别回答不同问题
- 若一张图已经解释“结构”，另一张图应解释“机制”或“演化”，不要换皮重复

## 7. AI 论文主图的稳定模式

- 系统总图优先采用“主链 + 支撑块”结构，不把所有细节压成一张扁平流程图
- 常见高质量布局是左到右或上到下主链，右上或右侧放局部机制块，底部放支撑视图
- 虚线框、局部放大框和独立 panel 用于拆开局部模块，不用于装饰
- 模块标题块、虚线容器和轻底色背景用于分组，但背景色必须低饱和
- 颜色优先承担模块语义、输入输出区分、时序层级区分，不做情绪化渲染
- 若图中存在多个张量块、模块块或对象块，同组颜色必须跨 panel 保持一致

## 8. AI 机制图的常见错误

- 主链不清楚，只剩大面积并列模块，读者看不出输入、处理、输出
- 局部解释块太多，抢走主图叙事
- 箭头过多、过长或交叉，导致结构阅读顺序混乱
- 颜色重复使用但语义不同，或同一语义跨 panel 随意换色
- 为了“高级感”堆过多 3D 透视、渐变、阴影和光效，破坏论文感
- 把 `禁止编造`、`禁止造假`、`结果复核`、`不得抄袭` 等流程治理词直接画进图内，造成污染
- 同批 2 到 4 张图布局原型、阅读方向和主色家族几乎完全一致，只剩换标题
