# 提示词骨架

## 目标

让每个 `xxx图.md` 都成为可直接交给图像模型的独立提示词文件，并强制收敛为统一三块协议。

## 唯一合法结构

```md
## 服务段落
放置在论文哪里、依据哪些段落或方法、对应哪一问、用到哪些知识、符号来源来自哪里。

## 生成图片的提示词
用于中文顶刊一区论文的科研绘图提示词……参考图组：当前 skill 的 `assets/reference-pictures/`。借鉴点：框架 / 结构 / 排版 / 思维链 / 配色。仅借鉴形式，不复制具体内容、数据、标签、结论。布局原型：……。阅读方向：……。主色家族：……。区分点：……。

## 硬约束
- 不渲染流程治理词为图内可见文字
- 图中文字全部中文且与论文符号一致
```

## 结构硬规则

- 不输出 `# 标题`
- 不输出额外 H2 或 H3
- 不把 `图类型`、`论文依据`、`核心变量/对象`、`视觉层级` 这类内容拆成单独小节
- 这些信息全部折叠进三块正文

## 三块职责

### 1. `## 服务段落`

必须说明：

- 这张图放在论文哪里
- 依据哪些段落、方法、结果或知识
- 对应哪一问或哪一类任务
- 变量、符号或对象的来源

### 2. `## 生成图片的提示词`

这里只写真正给图像模型的绘图提示词，必须覆盖：

- `参考图组：当前 skill 的 assets/reference-pictures/`
- `借鉴点：框架 / 结构 / 排版 / 思维链 / 配色`
- `仅借鉴形式，不复制具体内容、数据、标签、结论`
- 图的学术目的
- 需要表达的对象关系、输入机制输出或状态传播
- 主画面的构图与信息层次
- 局部机制、局部放大或支撑 panel
- 中文图内文字应显示什么
- 符号与论文一致
- `布局原型`
- `阅读方向`
- `主色家族`
- `区分点`

这里不得出现以下流程污染词：

- `禁止编造`
- `禁止造假`
- `结果复核`
- `三轮复核`
- `不得抄袭`
- `可复现`
- `可信输出`

### 3. `## 硬约束`

这里只放硬约束和负面约束。可写：

- 不渲染流程治理词为图内可见文字
- 不新增论文未定义的符号、数值、年份、地名、文献
- 避免高噪点、海报感、赛博感、商业宣传感
- 保持符号与论文一致

## AI 系图片默认原型

- 系统结构图：输入、核心模块、输出沿主链展开，局部机制放在右侧或右上支撑块
- 机制链路图：主画面讲作用链，支撑块讲局部算子、反馈或关键关系
- 模块交互图：分层分组表达变量、约束、模块和输出
- 时序/空间支撑图：只补最关键的时序、空间或局部放大逻辑

## 同批差异化要求

同批 2–4 张图至少在以下 4 项中的 2 项不同：

- 布局原型
- 阅读方向
- 主色家族
- 主视觉隐喻或区分点

## 负面约束固定项

- 避免引入过多噪点
- 避免过度 AI 味
- 避免过多 emoji
- 避免花哨发光、赛博特效、商业海报布局
- 避免用大段说明文字替代图像表达
- 避免把流程治理词渲染为图内标签
- 避免与同组其他图片重复构图或重复叙事
