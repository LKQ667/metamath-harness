# AI-Draw skills

## Overview

这个技能用于把“论文中的抽象方法描述”转成“可直接交给用户自行出图”的中文科研配图提示词。

先判断该段是否真的需要图，再决定是否插入占位框并生成 `手绘图/xxx图.md`。默认保持轻量、克制、中文顶刊一区风格，不生成图片，不堆砌说明文字。

## DeepSeek Harness mathmodel 入口契约

本 Skill 只能由用户手动调用。若请求包含 `dsh.mathmodel.request/v1`，其 `skill` 必须为 `ai-draw-skills`，直接消费卡片锁定的 `source_path`、`purpose`、`figure_type`、`style`、`aspect_ratio`、`prompt_count`、`prompt_only` 和 `userNotes`，不得重复询问；相对路径以当前工作区解析。

先按原文判断是否需要配图，再将 `purpose` 和 `figure_type` 视为偏好而非强制凑图。`由内容分析` 时由文稿关系决定；指定类型若不适合，必须解释原因并推荐更合适的类型。严格生成 `prompt_count` 份真正不同的方案（卡片允许 1–6），每份使用锁定的风格和比例，同时保持原有三块协议与污染词门禁。

无论 `prompt_only` 的值如何，本 Skill 都不调用 `image_generate` 或其他生图服务，也不把该布尔值视为付费授权；值为 false 时只额外给出可供用户后续手动生图的交接说明。任何实际生图都必须由用户另行明确授权原生工具。

所有 `手绘图/xxx图.md` 默认采用严格三块协议：

- `## 服务段落`
- `## 生成图片的提示词`
- `## 硬约束`

除这 3 个 H2 外，不输出 `# 标题`、额外 H2 或 H3。

## 固定工作流

1. 先判断当前段落是否需要原理图、模型图或概念示意图。
2. 如果需要，在文稿对应位置插入统一 Markdown 引用块占位框：

```md
> [图片占位]
> 手绘图/因果结构机制图.md
```

3. 深度学习当前文章涉及的方法、模型、原理与概念。
4. 优先读取以下信息源，按顺序吸收：
   - 当前论文正文、摘要、方法段、实验段
   - 当前工作区或相邻资料中的本地 PDF、截图蒸馏、学习索引
   - 本 skill `assets/reference-pictures/` 中已经内置的 AI 论文主图与截图蒸馏
   - 本技能 references 中的蒸馏规则与 4 篇首选样本
   - 必要时再补充权威科学来源，不用泛博客或营销材料
5. 在文稿同级或约定相对路径下创建 `手绘图/`，生成 2–4 个不重复的 `xxx图.md`。
6. 每个 `xxx图.md` 只对应 1 张图，且必须严格采用三块协议；`## 生成图片的提示词` 中不得出现流程污染词，`## 硬约束` 中若出现此类词，必须明确写成“不渲染为图内可见文字”。
7. 停止在提示词交付层，不调用图片生成工具，不替用户出图。

## 判断规则

- 需要图的常见信号：
  - 段落在解释机制、流程、模块关系、变量依赖、时空传播、因果路径、状态迁移
  - 文本单靠公式或叙述不易让读者快速形成结构理解
  - 适合拆成 `对象/结构 + 作用机制 + 量化支撑` 的层次
- 不需要图的常见信号：
  - 只是普通结果描述、泛泛结论、无明确结构关系的背景文字
  - 已有图能覆盖该信息，再加图只会重复
  - 段落只适合表格、曲线或数据图，而不是原理/模型示意图
- 不确定时，优先少插图，不为“看起来完整”硬加图。

## 输出要求

- 默认输出中文，UTF-8 编码。
- 默认每次生成 2–4 张图的提示词；如果主题很单薄，可少于 4 张，但不要凑数重复。
- 生成提示词前必须先读取本 skill `assets/reference-pictures/` 内置参考图组；后续生图模型也必须使用同一组本地参考图作为视觉参考。
- 图之间必须分工明确：
  - 一张负责对象与结构
  - 一张负责机制或流程
  - 一张负责关键关系或时序/空间逻辑
  - 需要时再补一张量化支撑或变体视角
- 同批提示词必须在至少 2 个维度上显式区分：
  - 布局原型
  - 阅读方向
  - 主色家族
  - 主视觉隐喻或区分点
- 不写“帮用户解释这张图为何如此设计”的长段说明。
- 不使用 emoji 风格表达，不写海报式夸张词。

## 风格硬约束

- 白底优先，层级清楚，少装饰，少背景噪点。
- 避免明显 AI 海报味、科幻 UI 味、泛商业宣传味。
- 颜色承担学术语义，不承担情绪渲染。
- 除主图必要标注外，避免在图内塞入大段解释文字。
- 同一任务下多张图不得换皮重复。
- 内置参考图组只允许借鉴框架、结构、排版、思维链、配色和阅读路径，不得复制其中的具体标签、数值、任务结论、实体名称或数据关系。
- `禁止编造`、`禁止造假`、`结果复核`、`三轮复核`、`不得抄袭`、`可复现`、`可信输出` 等流程词不得进入图内可见文字，也不得写入 `## 生成图片的提示词`。

## 默认参考策略

- 默认把当前用户文章放在第一优先级。
- 若本地存在 `顶刊论文/`、蒸馏截图、学习索引，优先吸收这些资料；本 skill `assets/reference-pictures/` 中已内置的 9 张 AI 论文主图与截图蒸馏默认视为最高优先级本地视觉知识源之一。
- 4 篇首选样本固定为：
  - 01 网络控制
  - 02 因果结构
  - 03 动力学发现
  - 04 物理过程
- 当前任务与 4 篇样本不完全一致时，选择最接近的结构原型来借鉴配色、布局和叙事顺序，而不是硬套具体视觉元素。

## 边界

- 这个技能只生成提示词与占位框，不直接生成图片。
- 这个技能不追求完整信息图，不做营销海报。
- 这个技能不复制特定论文的图像资产，只蒸馏顶刊级配色、布局、知识表达和思考链。
