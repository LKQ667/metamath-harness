# APMCM 中文赛模板要点

用户指定的 APMCM 中文赛 LaTeX 模板为首选模板；skill 内置 `assets/templates/main.tex` 只作为跨目录备用模板。

## DOCX 参考结构

若用户提供 APMCM 中文赛 DOCX 或 LaTeX 模板，以用户指定模板为准；不得把固定本机路径写入 workflow 规则。

- 首页顶部为三列表格：`选题`、`2024年第十四届APMCM 亚太地区大学生数学建模竞赛（中文赛项）`、`参赛编号`。
- 参赛编号示例为 `apmcm******`。
- 标题居中，摘要居中。
- 摘要及正文基本要求为宋体、小四号、单倍行距。
- 正文从下一页开始，原则上不超过 20 页。
- 参考文献可另起一页。
- 附录另起一页。

## LaTeX 约束

- 编译方式：XeLaTeX。
- 生成或更新 `论文/main.tex` 后必须立即编译；若编译失败，按最小改动修复并重新编译，直到 `main.log` 无硬错误、`main.pdf` 和 `main.aux` 存在，同时记录 `检查结果/latex_compile_record.md`。
- 不使用目录、普通 `\maketitle` 或普通 `abstract` 环境。
- 正文结构保留数学建模论文常用章节，但版式适配 APMCM 中文赛。
- 参考文献条目支持书籍、期刊、网上资源；网上资源必须写访问日期。
- 技术路线图、问题分析图和模型框架图最终必须来自 项目锁定的 Draw.io / AI 非数据绘图链路，并以 `\includegraphics` 插入正文。
- 技术路线图必须通过视觉密度、箭头路由、节点重叠、文字适配和风格非死板检查，避免大色块、长斜箭头和缩放后不可读。
- 原理图、模型图、概念示意图为必交内容，生成 2 到 4 份 `手绘图/xxx图.md` 提示词，并在文稿中显示该相对路径；每份提示词必须且只能包含 `## 服务段落`、`## 生成图片的提示词`、`## 硬约束` 三块。`## 生成图片的提示词` 必须显式写出 `参考图组：当前 skill 的 assets/reference-pictures/`、`借鉴点：框架 / 结构 / 排版 / 思维链 / 配色`、`仅借鉴形式，不复制具体内容、数据、标签、结论`，以及 `布局原型`、`阅读方向`、`主色家族`、`区分点`，且不得出现 `禁止编造`、`禁止造假`、`结果复核`、`三轮复核`、`不得抄袭`、`可复现`、`可信输出` 等流程污染词。若图内需要公式或符号，必须声明与论文符号说明、模型公式、唯一结果源和 `Qn/result.md` 一致。`手绘图/README.md` 负责说明依据项目锁定模式充分理解赛题、论文、代码和结果链，并先读取当前 skill `assets/reference-pictures/`；AI 模式直接调用当前环境的 `Image Gen/imagegen` 生图并回填，不依赖外部技能目录。
- 正文显示 AI 绘图提示词路径时，使用独立小段或换行排版，每行 1 个 `\texttt{手绘图/xxx图.md}`，不得把多个路径挤在同一长行。
- 正文不得使用 `itemize` 生成圆点项目符号；附录支撑材料文件目录只写纯文件名和简短说明，不写“文件/目录”“位置”“路径”列。
- 关键词和 `\label{abstract:end}` 后必须另开正文页，第一节“问题重述”不得与摘要同页。
- 支撑材料文件目录只列数据预处理代码、灵敏度分析代码、Q1-Q4 代码和题目明确要求的结果 `.xlsx/.xls/.csv`；附录代码文件只列完整 Q1-Q4 代码和完整灵敏度分析代码，且代码无注释。
- 附录代码块内部必须为纯代码，禁止注释、Markdown 围栏、装饰分隔线和连续大量空行。
