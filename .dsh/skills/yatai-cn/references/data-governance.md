# 数据治理规则

## 搜索优先级

1. 赛题原文、官方附件、APMCM 官方说明。
2. 国内外官网、政府部门、国际组织、行业主管机构、国家或地区统计平台。
3. 官方年鉴、开放数据平台、权威数据库。
4. 高质量论文、教材或报告中的可复核数据。
5. 新闻、博客、论坛只能作为线索，不得直接作为最终数据源。

## 禁止行为

- 不得为补齐模型输入而编造数值。
- 不得编造数据、文献、链接、机构、访问日期、字段或任何信息。
- 不得把无法打开或无法追溯的链接写成已核验来源。
- 不得静默删除异常值、缺失值或不利数据。
- 不得把估计值、插值值、假设值伪装成原始数据。

## `data.md` 记录格式

每条数据记录使用固定栏目：

```markdown
## 数据名称

- 来源机构：
- 来源链接：
- 访问日期：
- 获取方式：
- 文件位置：
- 字段说明：
- 数据作用：
- 适用问题：
- 可信等级：
- 清洗记录：
- 备注：
```

## `data.xlsx` 工作表

用户硬约束原文中的 `data.xlsl` 保持原文不改；实际执行和检查统一使用标准 Excel 工作簿 `数据/data.xlsx`。

- `数据清单`：数据集、来源机构、URL、访问日期、用途、状态。
- `原始数据索引`：原始文件名、下载链接、保存位置、校验信息。
- `清洗后数据`：可直接建模的数据表或索引。
- `字段说明`：字段名、含义、单位、类型、缺失说明。
- `来源映射`：模型变量、数据集、字段、来源 URL、处理方式。

## 数据缺失处理

- 先继续搜索权威数据。
- 找不到时，记录缺口、尝试过的来源和失败原因。
- 如需假设，必须写明假设依据、适用范围和对结果的影响。
- 论文正文不得跳过数据缺口说明。
