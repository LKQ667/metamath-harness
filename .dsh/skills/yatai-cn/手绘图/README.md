# 手绘图双模式协议

项目开始前必须选择 `Draw.io 绘图` 或 `AI 全自动绘图`，并把 `drawing_mode` 同步写入 `项目状态.json` 与 `figures/manifest.json` 后锁定。旧项目缺记录时补问，不根据目录内容猜测。

Draw.io 模式只自动生成流程图、问题分析流程图和技术路线图；原理图、模型图、概念图、示意图只保留 2–4 份 `手绘图/*.md` 提示词。AI 全自动模式逐份读取提示词并直接调用 `Image Gen/imagegen` 生成候选图和自动回填论文，另生成至少一张流程类图，不等待二次确认。

两种模式均须核对赛题、论文、数据台账、唯一结果源、Qn/result.md、核心代码和 manifest。AI 模式的提示词与成图必须一一对应；生成失败、文件不可解码、内容/中文/符号/裁切/清晰度/缩印/正文回填任一 QA 不合格时硬阻断，不得交付。

Draw.io 模式执行当前技能 `scripts/drawing/drawio_pipeline.py`，不得运行时调用外部绘图技能目录；CLI 验证、可编辑源、2× PNG、SVG、PDF 和论文插入缺一不可。
