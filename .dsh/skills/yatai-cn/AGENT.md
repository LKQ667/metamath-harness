# 亚太杯中文赛数学建模项目

## 项目规则

### 1. 语言与编码
- 全程使用中文，代码关键字和必要英文术语除外。
- 所有文本文件使用 UTF-8 编码。

### 2. 数据真实性
- 禁止编造数据、禁止编造文献、禁止编造信息、禁止编造任何内容。
- 外部数据必须官网优先，政府部门、国际组织、行业主管机构、国家或地区统计平台优先，并记录可点击来源链接。
- 任何新增数据都必须同步写入 `数据/data.md` 和 `数据/data.xlsx`。

### 3. 亚太杯中文赛特化
- 先理清题目，再找数据，不能为了建模方便倒推或伪造数据。
- 官方赛题、官方附件、政府/国际组织/行业官网、权威统计平台优先。
- 无法核验的数据只作为候选，不得进入论文结论。

### 4. 论文与图表
- 使用 APMCM 中文赛模板，不生成目录。
- 图表标题、图例、坐标轴、注释均使用中文。
- 流程图、技术路线图和问题分析图统一使用项目锁定的 Draw.io / AI 非数据绘图链路；Draw.io 模式保留 `.drawio`、2× PNG、SVG、PDF，AI 模式保留提示词与严格可解码 PNG，两者都必须有 manifest 记录。
- 原理图、模型图、概念示意图先生成 2–4 份 `手绘图/xxx图.md`；Draw.io 模式止于概念类提示词，AI 模式逐份自动调用 `Image Gen/imagegen` 生图并回填且不等待二次确认。提示词中的符号、公式必须与论文符号说明、模型公式、结果源和 Qn/result.md 一致。
- 生成或更新 `论文/main.tex` 后立即 XeLaTeX 编译，最小修复到无硬错误，并记录 `检查结果/latex_compile_record.md`。

### 5. 阶段状态自动更新区
- Step0：项目初始化与数据台账。
- Step1：题目拆解、权威数据搜索、数据预处理。
- Step2：逐问建模设计。
- Step3：代码实现、结果复现、图表生成。
- Step4：论文写作、排版、三轮自查、检查与交付。
