# 中文顶刊一区流程图风格

## 视觉原则

- 画面克制、清晰、可缩印：A4 论文中缩到单栏或双栏宽度仍能读清。
- 中文标签短句化：每个节点 4 到 12 个汉字为宜，必要时用 `<br>` 换行。
- 避免装饰性图形：不用阴影堆叠、渐变背景、手绘草稿风、默认彩虹色。
- 配色最多 5 类：输入/数据、方法/模型、算法/求解、验证/评价、输出/结论。
- 连线优先正交，箭头方向统一，分支条件写在边标签上。

## 推荐结构

1. 技术路线图：赛题输入 -> 数据审计 -> 问题拆解 -> 模型建立 -> 算法求解 -> 可靠性检验 -> 论文输出。
2. 单问求解流程图：输入数据 -> 预处理 -> 候选方法比较 -> 主模型 -> 参数估计 -> 结果校验 -> 结论。
3. 模型评价流程图：基准结果 -> 灵敏度分析 -> 误差来源 -> 稳健性检验 -> 优缺点评价 -> 改进方向。
4. 跨职能流程图：当“阶段”和“执行对象”同时重要时，用表格或泳道，不把所有节点挤在一条链上。

## 入文门槛

- 必须有 `.drawio` 源文件。
- 至少有一种论文图导出格式：PNG、SVG 或 PDF。
- PNG 宽度建议不低于 1600 像素；流程图较复杂时建议不低于 2400 像素。
- manifest 中必须写清用途、章节、源文件、导出文件、检查状态。
