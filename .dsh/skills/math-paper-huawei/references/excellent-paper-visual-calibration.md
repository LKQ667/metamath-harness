# 优秀论文视觉校准（华为杯专属）

`reference_excellent_papers=true` 时，本技能在共享发现脚本之上增加“视觉校准层”。目标不是证明模型心智状态，而是留下可审计的操作证据链：同题样本已发现 → 代表页已渲染 → 本地 PNG 存在 → 逐页观察记录存在 → Step4/Step5 引用该记录校准版式。

## 开关语义

- 开关只以锁定配置（`项目状态.json`）为准，缺省视为 false；非法类型按配置错误处理，检查器不从论文文本中出现的字段字符串推断开启。
- 开关关闭：不扫描论文库、不调用发现脚本、不创建 `截图/`、不生成报告，行为与既有流程一致；截图禁止入文的检查与开关无关，关闭时仍执行。
- 开关开启且发现脚本返回 `matched`：创建项目根 `截图/` 并渲染代表页，同时把权威报告写入 `检查结果/excellent_paper_visual_review.json`（`--output` 只是相同内容的额外副本）。
- 开关开启但返回 `catalog_missing`、`catalog_invalid`、`no_matching_sample`、`file_missing` 或 `hash_mismatch`：报告原样保存共享发现状态与真实回退原因（`file_missing`/`hash_mismatch` 不得写成普通“无样本”），可继续官方流程，但本次未完成视觉参考；开启却发现状态为 `disabled` 属状态冲突，必须核实后重跑。
- 共享脚本在缺省题号时也可能返回 `matched`（仅同赛事）。发现结果 `problem_match=false` 时必须在记录中写明“未能完成同题参考”，不得猜题号、不得当作同题校准。
- 仍只读取共享脚本返回的同赛事、同题号样本，最多两篇，保持 SHA-256 校验与 fallback 逻辑不变；`_shared/scripts/discover_excellent_papers.py` 与 `_shared/references/excellent-paper-policy.md` 不做任何修改。

## 执行步骤

1. 运行 `python "<技能目录>/scripts/excellent_paper_visual_review.py" --project "<项目根目录>" --competition 华为杯 --problem <当前题号>`；开关关闭时加 `--disabled`。
2. 脚本只消费共享发现脚本已校验通过的 PDF 路径，不重新扫描论文库。
3. 每篇按关键词定位代表页，默认 3–5 张，最多两篇；定位失败时按均匀抽样兜底，不使用 OCR、不下载依赖、不访问网络。
4. 输出目录结构：

```text
截图/
  优秀论文1/
    p001_摘要.png
    p012_模型建立.png
    p018_图表组织.png
  优秀论文2/
    ...
  优秀论文参考记录.md
```

5. 进入 Step4/Step5 前必须用 `read_image` 或 `vision_analyze` 逐个读取这些 PNG，再逐页回填 `截图/优秀论文参考记录.md`；没有视觉读取记录时不得声称“已参考优秀论文”。
6. 渲染器初始状态写“未读取，待完成视觉观察”，绝不预写“已读取”；相同样本（按 relativePath+sha256 内容身份）重跑时复用可用截图并保留已填写的观察；样本次序变化时观察跟随内容身份移动；同路径 PDF 内容变化（sha256 不同）后旧观察不复用，仅归档保留并标注“不参与本次统计”。
7. 每页观察必须具体描述标题密度、空白/图表占比、解释位置或文句组织；只写“版式好、布局好、文风好”三个词不算完成视觉阅读。渲染失败时报告具体失败页并保持“未读取”，不得写成“渲染成功”。

## 只可借鉴的抽象规律

- 页面留白与信息密度；
- 标题层级与段落节奏；
- 单图与多图的实际使用频率；
- 图表与解释的相对位置；
- 图表尺寸与版面占比；
- 摘要与问题段落的信息组织方式；
- 文风的克制程度与句式节奏。

## 永久禁止借鉴

- 样本原句或近似改写；
- 公式、变量、具体方法与结论的照搬；
- 数据、图表与数值结论；
- 样本中的装饰性项目符号与 AI 痕迹符号（含 `·`、`•`、`☐`）。

`截图/` 只作为项目内审计证据：绝不插入最终论文、不进入 `thebibliography`，也不复制到 `论文/`、`figures/` 或任何最终交付物。门禁 `check_excellent_paper_visual_reference.py` 以 `检查结果/excellent_paper_visual_review.json` 的已选样本与代表页清单为预期集合，用 PyMuPDF 逐张解码 PNG，逐样本（块止于下一个同级标题）逐页核对截图登记、页码对应与三维度观察实质内容；缺页、少样本、借观察、损坏 PNG、开启却 disabled 均不能通过，并阻止截图被 `\includegraphics` 引入论文（该检查与开关状态无关）。

## 回滚

移除本视觉校准层（脚本 + 门禁 + 本文件）并恢复卡片原描述即可回到“只校准完成度”的行为；已生成的 `截图/` 属用户项目数据，回滚时不得自动删除，共享发现脚本与论文库完全不受影响。
