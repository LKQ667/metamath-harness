# 华数杯数学建模竞赛项目

## 项目管理规则

### 1. 语言
- 全程必须使用**中文**（代码中的 Python 关键字除外），避免乱码，用 UTF-8 编码

### 2. 数据真实性
- **禁止编造数据、禁止胡编乱造、禁止篡改数据**。所有数据必须来源于题目附件、原始记录或明确可追溯的计算结果
- 若需假设数据，须明确标注“假设”及假设依据

### 3. 适用范围
- 本项目用于数学建模竞赛任务及同类建模任务
- 所有工作以题目或赛题要求为准绳

### 4. 学术诚信
- **禁止抄袭**。引用他人方法/成果须注明来源
- 在现有方法基础上适当创新，保持科学严谨性和真实性

### 5. 文档与代码规范
- 生成的**图片、Excel 文档与论文正文**必须统一使用卡片 `competition_language` 选择的中文或英文
- 图片标签、图例、标题、坐标轴与图内文字必须采用同一赛事语言，并达到顶刊一区 Top 1 绘图标准

### 6. 科研可视化标准
- Python 代码生成的图片必须达到**顶刊科研绘图标准**：
	- 分辨率 ≥ 300 dpi
	- 配色专业（避免默认色），使用顶刊常用色板
	- 图例、标题、坐标轴均为中文
- Python 数据图继续使用既有链路。非数据图在做题前必须由用户选择并锁定 `Draw.io 绘图` 或 `AI 全自动绘图`，同步记录到 `项目状态.json` 与 `figures/manifest.json`。
- Draw.io 模式仅自动生成流程类图并保留 `.drawio`、2× PNG、SVG、PDF；概念类图只交付 2–4 份提示词。AI 模式逐份自动生图并回填，另生成至少一张流程类图，不等待二次确认，失败或 QA 不合格时硬阻断。
- 两条链路运行时只使用当前技能内置资源，不依赖外部绘图技能目录。

### 7. 模型使用原则
- **必须非常谨慎**使用机器学习与深度学习方法，非必要不使用
- 优先使用机理模型、统计模型、运筹优化等确定性方法
- 严格执行项目锁定的 `bar_policy`：禁用时零例外禁止所有柱形绘图 API，时间轴/甘特图/区间图也必须改用线段与端点标记；少用时必须具备同源 manifest `bar_exception`；正常时仍按数据语义选图。
