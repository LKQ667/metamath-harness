# 完整候选路线的资格与比较

## 先固定同一个问题

从题意提取共同的目标量、硬约束、可用数据、随机生成/统计口径及输出精度。比较同一个问题的不同解法；不同解释或假设先作为前置分歧处理，不能借改变目标凑新路线。题意尚不能唯一确定时给条件性分析，不把解释选择包装成性能优势。

## 三道资格检查

1. **独立作答**：拿掉其他推荐的输出，该路线是否仍能从允许输入给出题目要求的完整答案？依赖题目规定的前问结果、公共数据预处理或公共几何内核不影响独立性；依赖另一候选先算出答案才做核验或修正，则通常是附属步骤。
2. **同题同层次**：目标、约束与交付要求是否相同？只输出误差条、初值、参数排名或敏感性结论的分析，不与求解主方法并列。稳健优化若额外引入最坏情景目标，是拓展；只有原题本就要求该目标时才能作为主候选。
3. **实质取舍**：能否说明两条路线在建模关系、估计对象、推断方式、优化结构或求解机制上的差异，且差异改变了可靠性、数据需求、适用性或成本？只改随机种子、调参数、换搜索器名称、加验证或改图表不算。共享物理模型或蒙特卡洛内核不意味着完全相同，仍需判断完整求解机制是否有实际不同。

内部给候选标记：完整路线 / 简单基线 / 路线内变体 / 公共验证 / 拓展 / 不适用。角色可兼容，例如能独立作答的基线也可能值得推荐，但“基线”身份不能替代资格检查。

## 合并与淘汰

- A、A 加置信区间、A 加灵敏度分析：合成一条 A 路线，后两者归验证或拓展。
- 预测模型、调参算法、预测区间：通常是同一链路的不同环节，不能当三个完整预测方案。
- 同一数学模型换两个求解器：默认是实现比较；只有带来可说明的精确性证书、规模能力或其他实质取舍，且都完整求解原题时，才作为独立候选。
- 连续空间导通问题中，临界根数分布反演与固定根数概率认证可以是两条完整求阈值路线；边界假设敏感性通常属于两者共用的拓展。共同几何内核不取消前两者的独立性。
- 解析近似只提供粗略初值而达不到原题精度时，不能作为第三条推荐。若误差可验证且能满足要求，可以成为完整候选；不要仅因它“理论味浓”推荐。
- 混合方案若只是另一候选加可选修饰，归路线内改进；若有独立成立的整体建模/求解机制和有证据的取舍，明确链路后再判断。

上述例子用于说明判别标准，不固定绑定某赛题或方法。不得为了多样性淘汰最佳路线，也不得为了创新选择明显不可行的方法。

## 数量与证据

默认最多三条；用户指定三个时努力寻找三个，但数量服从质量。只找到两条时直说“目前值得推荐的是两条”，指出第三类为何只适合辅助；不要留“待验证第三名”占位。已有路线足够且用户只要深化，不展开无关方案选秀。

初探的合格仅表示方法条件有依据，所有候选仍未实测；求解模式区分已验证、部分验证、失败。只把已完成验证且满足原题的路线写成已验证推荐。部分验证的备选可单列证据缺口，不能暗示排序已由实测证明。

最终比较用通俗问题复核：“我选它而不选另一条，实际会有什么不同？”答不出具体差异时合并或删去该推荐。基线比较、算法调试与消融可比最终推荐更多，无需把所有内部实验展示成用户选项。
