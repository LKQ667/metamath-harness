# 问题 3 建模设计：烘干所需时间

## 目标

按照“药材各处水分浓度低于 0.15 kg/kg”的烘干要求，确定药材烘干所需时间，并给出每隔
6 h、到药材中心距离每隔 0.5 cm 的水分浓度，以及每隔 60 s、径向每隔 0.1 cm 的完整结果。

## 输入

- 初始条件与几何同问题 1、问题 2。
- 边界工况：附件 1 的实测工况，t 超过 14400 s 后取末值 50.165 ℃、0.04986 kg/kg。
- 物性：题给附录 3 的经验式。

## 假设

1. 恒温干燥阶段烘房工况恒定，且整个烘干周期内不发生尺寸变化。
2. 烘干完成的判据取“所有径向位置的含水率同时低于 0.15 kg/kg”，即最大含水率首次低于阈值。
3. 干燥过程中不发生收缩、开裂与成分迁移导致的物性突变。
4. 烘房内的空气充分混合，药材表面各点工况一致。

## 变量

新增判据变量 C_th = 0.15 kg/kg 与终止时间 t_end；其余符号同问题 2。

## 公式

控制方程与边界条件同问题 2。烘干时间定义为

    t_end = min { t : max_{0 ≤ r ≤ R} C(r,t) < C_th }

最大含水率出现在药材中心，因此该判据等价于中心含水率首次低于 0.15 kg/kg。由此得到的
烘干时长可用扩散时间尺度做量级校核：

    t_diff ~ R² / D_eff

其中 D_eff 取干燥后期的扩散系数，用于说明结果是否落在合理区间。

## 约束

- 时间单调推进，一旦满足判据立即终止，不做超出判据的额外推进。
- 烘干时长必须为正且落在题目给出的 2—3 天量级附近。
- 终止时刻的中心含水率不得超过阈值。

## 方法

沿用问题 2 的隐式有限体积求解器，时间步长放宽到 10 s，每 60 s 记录一次；每一步检查
最大含水率是否低于 0.15 kg/kg，首次满足时停止并记录时间。为控制内存，只保留径向
每隔 0.1 cm 的节点。

## 验证

- 时间步无关性：把时间步长从 10 s 减半到 5 s，比较烘干时间。
- 判据一致性：确认终止时刻全部径向节点的含水率均低于 0.15 kg/kg。
- 量级校核：用扩散时间尺度估算的时长与实际计算值对比，两者应在同一数量级。

## 与下一问衔接

本问假设尺寸不变。问题 4 引入药材失水收缩，需要把固定域换成移动边界，并重新评估收缩
对烘干时间的影响。
