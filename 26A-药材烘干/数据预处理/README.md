# 数据预处理说明

## 原始输入

| 文件 | 内容 | 规模 |
| --- | --- | --- |
| 赛题/附件/附件1.xlsx | 烘房温度（℃）与水分浓度（kg/kg）随时间变化 | 241 条，0—14400 s，步长 60 s |
| 赛题/附件/附件2.xlsx | 药材半径（cm）随时间变化 | 145 条，0—259200 s，步长 1800 s |
| 赛题/附件/附件3/result1..4.xlsx | 四份结果工作簿模板 | 列名与时间步长模板 |

原始附件以只读方式使用，`data/raw/` 下保存逐字节副本，保证离线可复现。

## 处理规则

1. 列名统一为“时间/温度/水分浓度”与“时间/半径”，并强制转换为浮点数。
2. 丢弃任一列缺失的记录；同一时间点若重复出现，保留首次出现的记录。
3. 按时间升序重排，保证插值函数单调可逆。
4. 不对原始数值做任何平滑、滤波、截断或量纲换算。
5. 附件 1 只覆盖 0—14400 s。问题 2—4 的恒温干燥阶段按题面“两阶段参数不同”的说明
   取附件 1 末值作为恒定工况，该处理属于建模假设，在论文与各问结果说明中标注。

## EDA

`data/derived/eda_summary.json` 汇总了以下结论：

- 附件 1：241 条记录，无缺失、无重复，时间严格递增；温度 28.000—50.165 ℃，
  水分浓度 0.019630—0.049860 kg/kg；两者 Pearson 相关系数接近 1，说明升温与蒸发同步。
- 附件 2：145 条记录，无缺失、无重复，时间严格递增；半径 2.000—1.198 cm，
  单调不增，收缩幅度 0.802 cm，后段趋于平稳。
- 两份附件的量级差异说明烘房水分浓度与药材含水率是两个不同尺度：前者约 10⁻² kg/kg，
  后者约 10⁰ kg/kg，因此传质边界条件必须用浓度差驱动而不是直接取等。

## 输出

| 文件 | 用途 |
| --- | --- |
| data/derived/ambient_conditions.csv | 规整后的烘房工况，供问题 1—4 读取 |
| data/derived/radius_profile.csv | 规整后的半径序列，供问题 4 重建 R(t) |
| data/derived/eda_summary.json | EDA 结论的机器可读汇总 |
| 数据预处理/figures/fig_eda_ambient.* | 烘房工况演化与温度—浓度关系图 |
| 数据预处理/figures/fig_eda_radius.* | 半径收缩轨迹与收缩速率图 |

## 结论

- 数据完整、无异常值，可直接进入建模链路，不需要插补或剔除。
- 烘房温度与水分浓度高度同步上升，说明预热平衡阶段的边界工况是“升温 + 增湿”组合，
  不能把烘房水分浓度当作恒定值处理。
- 半径单调收缩且收缩速率在前期快速衰减，问题 4 必须使用保形插值重建连续收缩曲线，
  并对 72 h 之后按末值保持而不外推。
- 上述结论直接决定问题 1 使用常数物性、问题 2—3 使用随含水率变化的经验式、
  问题 4 使用移动边界的建模路线。
