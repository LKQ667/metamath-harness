# 问题 4 建模设计：考虑失水收缩的烘干时长

## 目标

考虑药材因水分流失发生的尺寸变化，根据附件 2 的实测半径，重新确定烘干时长，并给出
每隔 6 h、到药材中心距离每隔 0.5 cm 的水分浓度与每隔 60 s、径向每隔 0.1 cm 的完整结果。

## 输入

- 附件 2：0—259200 s（72 h）每隔 1800 s 的药材半径，由 2.000 cm 单调收缩到 1.198 cm。
- 附录 4 的物性经验式：ρ = 760 + 90C、cp = 1850 + 2150C/(C+1)、k = 0.12 + 0.20C/(C+1)、
  D = 4.2×10⁻⁴ exp(−0.30/C) exp(−3850/T)。
- 边界工况与初始条件同问题 3。

## 假设

1. 收缩是各向同性的均匀收缩：药材内部任意一点的相对位置保持不变，半径按同一比例缩小。
2. 半径随时间的变化由附件 2 的实测序列经保形插值给出；超过 72 h 后按最后实测值保持，
   不做外推。
3. 收缩只改变几何尺度，不改变含水率与温度的物理含义，物性仍按附录 4 的含水率经验式取值。
4. 表面换热与传质系数沿用 h = 25 W/(m²·K)、h_m = 8×10⁻⁷ m/s。

## 变量

新增 R(t) 当前半径、Ṙ(t) 收缩速率、ξ = r/R(t) 无量纲径向坐标；其余符号同问题 3。

## 公式

在固定坐标 ξ 上，控制方程变为带对流项的扩散方程：

    ∂C/∂t|_ξ = (D/(ξR²)) ∂/∂ξ ( ξ ∂C/∂ξ ) + ξ (Ṙ/R) ∂C/∂ξ

能量方程形式相同，把 D 换成 α = k/(ρcp)。边界条件在 ξ = 1 处为

    −(D/R) ∂C/∂ξ = h_m (C − C_air(t))

在 ξ = 0 处保持对称。对流项系数 ξṘ/R 恒为非正，表示坐标随收缩向中心压缩。

## 约束

- 半径必须单调不增且不小于附件 2 的最小实测值。
- 收缩速率在 72 h 之后取零，禁止用多项式外推延长实测序列。
- 计算域在 ξ 空间恒为 [0,1]，物理域随 R(t) 收缩。
- 烘干判据仍为最大含水率首次低于 0.15 kg/kg。

## 方法

把物理域映射到固定域 ξ ∈ [0,1]，扩散项用隐式有限体积，对流项用中心差分，时间步长 10 s，
每 60 s 记录一次。半径与收缩速率由附件 2 的单调保形插值给出，保证不产生虚假振荡。

## 验证

- 退化检验：把 R(t) 强制设为常数 2 cm 并用附录 3 的物性，结果应与问题 3 一致。
- 收缩一致性：计算得到的最终半径应与附件 2 在终止时刻的实测半径吻合。
- 质量守恒：按表面积分的水分损失应与内部含水率下降总量一致。

## 与下一问衔接

的烘干时长，可直接回答“实际烘干过程中药材需要烘多久”。
