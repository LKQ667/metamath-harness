# 问题 1 建模设计：预热平衡阶段的温度—水分浓度场

## 目标

在预热平衡阶段（0—1800 s）给出圆柱形药材内部温度与干基含水率的时空分布，并按题面
表 1、表 2 的格式输出 100、300、600、900、1200、1500、1800 s 与到药材中心距离
0、0.5、1、1.5、2 cm 的结果，同时把 1800 s 内每隔 1 s、径向每隔 0.1 cm 的完整结果
写入结果工作簿。

## 输入

- 几何：圆柱长 25 cm、半径 R = 2 cm；径向一维，轴向均匀。
- 初始条件：T(r,0) = 28 ℃，C(r,0) = 2.55 kg/kg。
- 边界工况：烘房温度 T_air(t) 与水分浓度 C_air(t) 取自附件 1 的 241 条记录。
- 物性：ρ = 820 kg/m³、cp = 2600 J/(kg·K)、k = 0.36 W/(m·K)、h = 25 W/(m²·K)、
  h_m = 8×10⁻⁷ m/s、D = 7×10⁻⁹ exp(−0.89/C) m²/s。

## 假设

1. 药材视为均质各向同性圆柱，温度与含水率只沿半径变化，忽略轴向与周向梯度。
2. 预热平衡阶段不发生尺寸变化，半径固定为 2 cm。
3. 干燥初期药材表面与烘房空气之间只通过表面对流换热与对流传质交换热量和水分。
4. 物性 ρ、cp、k 取常数；水分扩散系数随含水率变化，遵循题给经验式。
5. 烘房空气的温度与水分浓度在任意时刻沿空间均匀，附件 1 的离散工况之间线性插值。

## 变量

| 符号 | 含义 | 单位 |
| --- | --- | --- |
| r | 到药材中心的距离 | m |
| t | 时间 | s |
| T(r,t) | 药材温度 | ℃ |
| C(r,t) | 干基含水率 | kg/kg |
| D(C) | 水分扩散系数 | m²/s |
| h | 对流换热系数 | W/(m²·K) |
| h_m | 对流传质系数 | m/s |

## 公式

质量守恒（圆柱径向）：

    ∂C/∂t = (1/r) ∂/∂r ( D(C) r ∂C/∂r )

能量守恒：

    ρ cp ∂T/∂t = (1/r) ∂/∂r ( k r ∂T/∂r )

边界条件：

    r = R :  −D ∂C/∂r = h_m (C − C_air(t)),  −k ∂T/∂r = h (T − T_air(t))
    r = 0 :  ∂C/∂r = 0,  ∂T/∂r = 0

## 约束

- 含水率非负，温度不高于烘房温度与初始温度构成的区间包络。
- 对称轴上热流与质量流为零。
- 边界通量方向由药材表面与烘房空气的温差、浓度差决定。

## 方法

对节点中心有限体积离散，界面扩散系数取相邻节点算术平均，时间推进用后向 Euler
隐式格式，每步解一个三对角线性系统；网格 200 等分（径向步长 0.01 cm），时间步长 1 s。

## 验证

- 网格与时间步收敛：把径向步长减半、时间步长减半，比较 1800 s 时刻特征点结果。
- 守恒性：按表面对流通量积分得到的水分损失与内部含水率降低量对比。
- 合理性：中心点温度始终低于表面点，表面点温度不高于同期烘房温度。

## 与下一问衔接

本问确定的控制方程、离散格式与边界处理直接复用到问题 2；问题 2 只需把常数物性替换为
随含水率变化的经验式，并把烘房工况从 4 h 延伸到整个烘干周期。
