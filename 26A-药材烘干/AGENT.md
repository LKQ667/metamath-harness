# AGENT.md —— 项目执行规约与阶段状态

本文件是本项目的自动化执行规约。所有阶段产物、门禁结论与运行记录都以此处为准，
阶段状态自动更新区由执行代理在每阶段门禁通过后写入，禁止人工手改结论。

## 一、硬性纪律

- 禁止编造：不得虚构数据、公式、参数、实验结果、图表数值、参考文献或代码运行结果；
  任何数值都必须能由 `results/final_results.json` 与对应脚本复现。
- 禁止篡改：不得修改赛题原文与官方附件，不得改写已通过的阶段报告、门禁记录与附录代码
  复核记录，不得为通过检查而伪造 QA 状态。
- 数据来源：全部数据来自赛题目录下的附件 1、附件 2 与附件 3 结果模板，逐条登记在
  `data/source_map.md`；未登记来源的数据不得进入建模、图表或正文。
- 结果唯一源：所有最终数值先写入 `results/final_results.json`，论文、摘要、各问
  result.md 与结果工作簿只能引用该文件，禁止保留互相冲突的多套结果。
- 语言一致：正文、图题、图例、坐标轴与图内文字统一使用中文。
- 绘图策略：柱状图策略为“少用”，仅在类别很少、必须零基线且核心任务是绝对高度比较，
  并在同源 manifest 条目写明完整 bar_exception 时才允许柱形 API。
- 非数据绘图：采用 Draw.io 成图 + AI 概念提示词模式，流程类图由 Draw.io 生成，
  原理/模型/概念示意图只保留提示词，不调用付费生图。
- 门禁优先：每个阶段完成后必须运行项目内门禁入口，退出码非 0 时先完整读取该阶段的
  failures_summary.json 清单，一次性修复全部失败项后重跑，直至通过。

## 四、失败与恢复

- 同一失败原因最多连续重试三次，仍失败则切换安全替代方案并在检查结果中留痕。
- LaTeX 环境已探测为宿主 TeX Live 2025，若缺包通过宏包管理器补齐后重试。
- Draw.io 导出依赖桌面端 CLI，运行前清理继承的 Node 运行时环境变量并追加无沙箱参数。
