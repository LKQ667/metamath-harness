# 问题 2 结果说明：整个烘干过程的温度与水分浓度场

## 问题目标

给出整个烘干过程（预热平衡 + 恒温干燥）的数学模型，输出 3 h 内每隔 0.5 h、径向
0、0.5、1、1.5、2 cm 处的温度与水分浓度，并保存每隔 1 s、径向每隔 0.1 cm 的完整结果。

## 输入数据

- `data/derived/ambient_conditions.csv`：烘房工况，0—14400 s；其后按恒温干燥假设取末值
  50.165 ℃、0.04986 kg/kg。
- 题给经验式（附录 3）：ρ = 650 + 128C、cp = 1450 + 2736C/(C+1)、k = 0.21 + 0.38C/(C+1)、
  D = 2.4×10⁻³ exp(−0.45/C) exp(−3850/T)。
- 初始条件：T = 28 ℃、C = 2.55 kg/kg。

## 核心假设

均质径向一维；3 h 内尺寸不变；两阶段共用控制方程，仅切换边界工况与物性经验式；恒温
干燥阶段烘房工况恒定；表面换热与传质系数沿用问题 1。

## 模型思路

把问题 1 的常数物性换成题给经验式，得到强耦合的非线性系统：含水率下降使密度、比热容、
导热系数同时下降，而扩散系数随含水率下降呈指数衰减，于是干燥速率随含水率降低而快速
减小。数值上沿用隐式有限体积，用上一时刻的物性做线性化。

## 关键公式通俗解释

ρ(C) = 650 + 128C 说明药材越湿密度越大；cp(C) = 1450 + 2736C/(C+1) 说明湿药材升温需要
更多热量；k(C) = 0.21 + 0.38C/(C+1) 说明水分提高导热能力；D(C,T) 中 exp(−0.45/C) 表示
含水率越低水分越难迁移，exp(−3850/T) 表示温度越高迁移越快。三项合起来解释了“前期升温
伴随快速失水、后期靠温度维持缓慢失水”的过程。

## 结果解释

温度在 2 h 内基本完成过渡：中心温度从 28 ℃ 升到 48.7919 ℃，3 h 时已达 49.9065 ℃，
与烘房温度 50.165 ℃ 只差 0.2585 ℃，说明热扩散特征时间约 1.2×10³ s，远小于 3 h。
含水率的变化则呈现明显的“外层快、内层慢”：3 h 时表面已降至 1.0070 kg/kg，而中心仅由
2.55 降到 1.7601 kg/kg。原因在于 D 随含水率指数衰减，表面一旦变干，其自身的扩散能力
迅速下降，干燥速率由内部向表面的水分输运控制。表中 0 与 0.5 cm 两列的差值只有 0.0491，
说明中心区域在 3 h 内仍近似同步变化。
