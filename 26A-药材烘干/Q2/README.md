# 问题 2 建模设计：整个烘干过程的温度—水分浓度场

## 目标

建立覆盖预热平衡与恒温干燥两个阶段的整体模型，给出 3 h 内每隔 0.5 h、到药材中心距离
0、0.5、1、1.5、2 cm 处的温度与水分浓度，并把每隔 1 s、径向每隔 0.1 cm 的完整结果写入
结果工作簿。

## 输入

- 初始条件与几何同问题 1。
- 边界工况：附件 1 的 T_air(t)、C_air(t)；t 超过 14400 s 后按题面“两阶段参数不同”的
  说明取附件 1 末值（50.165 ℃、0.04986 kg/kg）作为恒温干燥阶段的恒定工况。
- 物性改为题给经验式：ρ = 650 + 128C、cp = 1450 + 2736C/(C+1)、k = 0.21 + 0.38C/(C+1)、
  D = 2.4×10⁻³ exp(−0.45/C) exp(−3850/T)。

## 假设

1. 同问题 1 的均质、径向一维、轴向均匀假设。
2. 3 h 内药材尺寸变化可忽略，半径仍取 2 cm。
3. 预热平衡与恒温干燥的差别只体现在烘房工况与物性经验式的切换，不改变控制方程形式。
4. 恒温干燥阶段烘房保持 50.165 ℃、0.04986 kg/kg 不变。
5. 表面换热系数与传质系数仍取 h = 25 W/(m²·K)、h_m = 8×10⁻⁷ m/s。

## 变量

在问题 1 的变量基础上增加：ρ(C) 密度、cp(C) 比热容、k(C) 导热系数、D(C,T) 扩散系数。
温度 T 在经验式中以开尔文代入，输出仍用摄氏度。

## 公式

质量守恒与能量守恒形式同问题 1，但系数随含水率变化：

    ∂C/∂t = (1/r) ∂/∂r ( D(C,T) r ∂C/∂r )
    ρ(C) cp(C) ∂T/∂t = (1/r) ∂/∂r ( k(C) r ∂T/∂r )

边界条件同问题 1。含水率升高时 ρ 增大、cp 增大、k 增大，扩散系数随含水率降低而急剧
下降，因此方程呈现“先快后慢”的强非线性特征。

## 约束

- 两个阶段共用同一套控制方程与初始条件，只在边界工况上分段。
- 含水率与温度必须连续，不允许在阶段切换处出现跳变。
- 含水率非负且单调下降，温度单调上升并趋近烘房温度。

## 方法

沿用问题 1 的节点中心有限体积与后向 Euler 隐式格式；每一步用上一时刻的 ρ、cp、k、D
线性化，界面扩散系数取算术平均。网格 200 等分（0.01 cm），时间步长 1 s，共 10800 步。

## 验证

- 与问题 1 对比：在 0—1800 s 且物性取常数的极限下，本问结果应退化到问题 1 的量级。
- 阶段切换连续性：检查 14400 s 前后含水率与温度曲线是否平滑。
- 物性合理性：检查 ρ(C)、cp(C)、k(C) 在 C ∈ [0.05, 2.55] 上的取值范围是否落在
  湿药材的常规区间内。

## 与下一问衔接

本问的模型可以长时间推进，因此问题 3 直接以本问的求解器为基础，把终止条件改为
“各处含水率低于 0.15 kg/kg”，用于确定烘干所需时间。
