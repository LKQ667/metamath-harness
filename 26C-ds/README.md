# 2026 华为杯 C 题：服务于脑机接口与精神性疾病诊断的脑电图计算模型

本仓库为 2026 中国研究生数学建模竞赛 C 题的完整建模与论文工程，覆盖数据预处理、三问建模、代码实现、论文写作与 PDF 交付全链路。

## 一、题目与任务

题面围绕视觉认知实验展开：被试在 F3、Fz、F4 三个前额点位采集脑电，完成两类识别任务（项目一预先知道目标位置、项目二只知道目标形状而位置未知）。需要完成三项工作。

1. 针对实验项目一与项目二，对给定脑电数据做资料预处理，在保留视物形状脑电特征的前提下去除运动、眨眼等伪影，提取不同观测点位的有效视觉响应并拟合曲线。
2. 建立脑电计算模型，说明从 LGN 到皮层、再到头皮观测脑电的机理，解释左、右三角刺激产生脑电信号差异的形成机制，并给出能区分左、右三角形视觉刺激响应的特征表示。
3. 截取与视觉认知相关联的信号，借助第二问的脑电形成机制并考虑信号可能同时来源于海马体与 LGN，建立认知的宏观模型，并用题目提供的脑电信号验证该模型。

## 二、数据

四份原始记录 `VisualCogA_Task-1.mat`、`VisualCogA_Task-2.mat`、`VisualCogB_Task-1.mat`、`VisualCogB_Task-2.mat`，采样率 256 Hz，每份 10 个通道、各含 100 个试次。

通道语义为 Fz、F3、F4（原始信号），FzDecon、F3Decon、F4Decon（设备自带滤波输出，本项目不直接使用），ECG（参考），VisCue（视觉提示，−1 左靶 / +1 右靶），TgtAct（目标应答，−2 左 / +2 右），TimeStamp。

数据来源与派生关系登记在 `data/source_map.md`。

## 三、依赖环境

- Python 3.12，依赖 NumPy、SciPy、Matplotlib、pandas
- XeLaTeX（TeX Live 2025），中文字体 SimSun、SimHei、Times New Roman、Cambria Math
- 绘图链路：Matplotlib（数据图）、Draw.io CLI（流程类图）
- 门禁入口：项目内 `scripts/checks/`

## 四、运行命令

项目内门禁入口（每个阶段完成后运行）：

```
python scripts/checks/run_stage_gate.py --project . --stage step0
```

最终交付验证：

```
python scripts/checks/verify_delivery.py --project .
```

数据预处理与逐问求解脚本分别位于 `数据预处理/`、`Q1/`、`Q2/`、`Q3/`，各问运行方式见对应 `README.md` 与 `result.md`。

## 五、最终结果

唯一结果源为 `results/final_results.json`。论文、摘要、本文件与各问 `result.md` 中的数值均引用该文件，不保留互相冲突的多套结果。

## 六、复现步骤

1. 确认 `data/raw/` 下四份原始记录存在（与 `赛题/` 内文件一致）。
2. 运行 `数据预处理/preprocess_eeg.py`，生成分段与去噪派生数据，并写入 `数据预处理/audit.json`。
3. 依次运行 `Q1/solve_q1.py`、`Q2/solve_q2.py`、`Q3/solve_q3.py`，生成逐问结果与图件。
4. 运行 `灵敏度分析/` 下脚本生成敏感性图。
5. 生成非数据图（Draw.io 链路），更新 `figures/manifest.json`。
6. 编译 `论文/main.tex`（XeLaTeX）得到最终 PDF。
7. 运行阶段门禁与最终交付验证，确认退出码为 0 且输出 `ok: true`。

## 七、异常处理记录

- 原始记录中 VisCue 与 TgtAct 为稀疏事件标记通道，需按标记跳变切分试次，不能按固定间隔等分。
- 部分试次记录中存在幅值达 ±1000 的明显伪迹，须在分段后按稳健准则识别并标记，不得直接删除而不留记录。
- 通道 4–6 为设备自带滤波输出，与自建去噪结果存在系统性差异，仅用于对照，不作为建模输入。
