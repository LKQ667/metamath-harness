# 问题二结果说明

## 问题目标

建立从 LGN 到皮层、再到头皮观测的脑电计算模型，说明视觉刺激逐级转化为头皮电位的机理；解释左右三角刺激产生脑电信号差异的形成机制；给出能区分左右三角形视觉刺激响应的特征表示。

## 输入数据

问题一输出的去噪分段信号 `data/derived/epochs_*.npz`（三导联、逐试次、刺激前 0.2 s 至刺激后 1.0 s）与有效响应特征 `data/derived/erp_features.csv`。刺激几何为水平镜像的左指与右指三角。

## 核心假设

1. 视觉通路可用"视网膜—LGN—初级视皮层—高级形状区—头皮"的串行前向链刻画。
2. LGN 时空响应可分离为空间差分高斯核与因果 Gamma 时间核的乘积。
3. 形状选择性神经元的偏好模板在左右刺激之间互为镜像。
4. 皮层集群活动由 Wilson–Cowan 型平均场方程描述。
5. 头皮电位是神经元群同步活动序参数的宏观汇集，经容积传导空间低通加权。
6. 前额三导 Fz、F3、F4 的导联场随源到电极距离单调衰减。

## 模型思路

模型分五级串联。刺激图先经差分高斯空间滤波与因果 Gamma 时间核卷积得到 LGN 输出场；该场经多方向 Gabor 滤波器组做匹配滤波并做除法归一化，得到形状选择性单元响应；响应驱动含局部兴奋、周边抑制与适应电流的神经质量方程；集群活动的相位同步度由序参数度量；最后经导联场投影到三导。

左右差异的几何来源是偏好模板的镜像关系。由于 Fz 位于中线，镜像源的贡献在其上相消；F3 与 F4 分别偏向两侧，其导联场权重对镜像源集合互换，因此差分 F4−F3 对镜像差异最敏感。

## 关键公式通俗解释

- 差分高斯刻画中心—周边拮抗的对比敏感特性，因果 Gamma 核给出 LGN 的延迟与瞬态响应。
- 匹配滤波能量对相位不敏感，除法归一化使响应只依赖特征组合的相对强度，对应题面所述"轮廓包裹双眼、双眼位于嘴部上方"式结构判据。
- Wilson–Cowan 方程中的 (1−E) 与 (1−I) 因子自动把平均活动限制在 0 与 1 之间。
- 序参数幅值度量振子群的相干性，取值在 0 与 1 之间。
- 导联场是空间低通算子，这正是头皮观测只能看到源的宏观汇集的数学表现。

## 核心数值结果

**镜像性检验**。左指刺激的皮层响应与右指刺激响应的水平镜像逐点平均绝对误差为 0.0000，说明模型的镜像对称结构被正确实现；刺激图本身的镜像误差同样为 0.0000，而两幅刺激图的非镜像差异为 0.1476，证明二者确实互为镜像而非相同图像。

**偏侧预测**。右指与左指刺激的头皮偏侧响应峰峰值均为 0.0528 且符号相反，即模型预测左右刺激产生方向相反的偏侧响应。Fz 对镜像差异的不敏感度为 0.0000，与"Fz 位于中线、镜像贡献相消"的机制推论一致。

**时间窗对照**。慢维持通路参数标定后，模型预测的偏侧时程与实测偏侧时程相关系数为 **0.8718**；预测的晚期与早期偏侧幅度比为 1.1166，实测为 0.5849，两者同向但模型相对高估早期成分。

**左右判别特征性能**（五种子分层五折交叉验证 AUC 平均）。

| 记录 | 早期形状特征（Fz，80–250 ms） | 晚期偏侧特征（F4−F3，250–800 ms） | 联合特征 |
|------|-------------------------------|-----------------------------------|----------|
| A 组项目一 | 0.6136 | 0.5478 | 0.5537 |
| A 组项目二 | 0.5733 | 0.6108 | 0.5792 |
| B 组项目一 | 0.5431 | 0.4886 | 0.5250 |
| B 组项目二 | 0.5000 | 0.5767 | 0.5480 |
| 四记录均值 | 0.5575 | 0.5560 | 0.5515 |

联合特征在四个记录上的取值区间为 0.5250 至 0.5792，全部高于随机水平。

**判别方向**。以线性判别分析在四份记录上拟合的判别权重显示，早期形状特征与晚期偏侧特征贡献同号且量级相当，说明左右信息由"形状编码"与"空间偏侧编码"两部分共同承载，而不是单一导联的幅值。

## 结果解释

图4 显示判别权重在刺激前窗口存在一段与刺激无关的负向偏置，在刺激后 250 ms 之后转为正向并持续增强，同时 F3 与 F4 呈现相反的符号结构。这与模型预测的"中线导联对镜像差异不敏感、偏侧导联敏感"一致。

图5 显示镜像差异场在 Fz 中线两侧呈符号相反的成对结构：左侧为正（右指更强），右侧为负（左指更强），而三个观测点正好落在该结构的正负过渡带上。这解释了为什么差分 F4−F3 比单导幅值更能区分左右刺激。

早期形状特征在项目一记录上表现更好（0.5431 与 0.6136），晚期偏侧特征在项目二记录上表现更好（0.5767 与 0.6108）。这与实验设计吻合：项目一的提示已经指示了目标位置，被试在早期即可完成形状与位置的联合编码；项目二只给形状，空间信息需要更长时间维持。

## 局限与下一问衔接

模型在 B 组项目一记录上的偏侧特征 AUC 为 0.4886，略低于随机水平，说明该条件下偏侧信息不可用，联合特征仍靠形状特征维持在 0.5250。模型的预测偏侧幅度比与实测的差异（1.1166 对 0.5849）说明快慢通路的相对权重还需进一步标定。
