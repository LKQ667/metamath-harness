# 问题二：脑电计算模型与左右刺激区分特征

## 目标

建立从外侧膝状体（LGN）到大脑皮层、再到头皮观测的脑电计算模型，说明视觉刺激如何逐级转化为可观测的头皮电位；用该模型解释左、右三角形刺激所产生脑电信号差异的形成机制；给出能区分左、右三角形视觉刺激响应的特征表示。题面提示形状识别依赖"特定空间方式排列的特征组合"，因此模型必须显式包含形状选择性神经元的空间排列，并让左右刺激对应镜像的空间响应分布。

## 输入

- 问题一输出的去噪分段信号 `data/derived/epochs_*.npz`（三导联、逐试次、[-0.2, 1.0] s）。
- 问题一输出的有效响应特征 `data/derived/erp_features.csv`。
- 题面给定的多尺度模型方程：微观 LIF 方程、介观 Wilson–Cowan 平均场方程、宏观 Kuramoto 相位方程与序参数定义。
- 刺激几何：左指三角与右指三角为水平镜像，形状特征为"顶点方向 + 底边位置"的组合。

## 假设

1. 视觉通路可用"视网膜—LGN—初级视皮层—高级形状区—头皮"的串行前向链刻画，各阶段的时空尺度依次增大。
2. LGN 的时空响应可分离为空间差分高斯核与因果 Gamma 时间核的乘积。
3. 形状选择性神经元对"特定空间排列的特征组合"响应，其偏好模板在左右刺激之间互为镜像。
4. 皮层神经元群的平均活动可由 Wilson–Cowan 型平均场方程描述，兴奋—抑制耦合强度在刺激期间近似恒定。
5. 头皮电位是大量神经元群同步活动的宏观汇集，可由 Kuramoto 序参数经容积传导加权得到。
6. 三导联 Fz、F3、F4 的观测算子为空间低通加权，权重由电极与前额皮层的几何关系决定。

## 变量

| 符号 | 含义 |
|------|------|
| $I(\mathbf{x},t)$ | 视网膜输入强度分布 |
| $L(\mathbf{x},t)$ | LGN 输出场 |
| $K_{\text{LGN}}$ | LGN 时空响应核 |
| $\mathbf{w}_j(\mathbf{x})$ | 第 $j$ 个皮层单元的偏好特征模板 |
| $u_j(t)$ | 第 $j$ 个皮层单元的驱动输入 |
| $E_j(t),\,I_j(t)$ | 第 $j$ 个集群的兴奋、抑制平均活动 |
| $\theta_n(t),\,\omega_n$ | 第 $n$ 个振子的相位与固有频率 |
| $C_{np},\,\tau_{np}$ | 结构连接权重与传导延迟 |
| $r(t),\,\psi(t)$ | Kuramoto 序参数幅值与平均相位 |
| $A_{mn}$ | 第 $n$ 个源到第 $m$ 个电极的导联场权重 |
| $y_m(t)$ | 第 $m$ 个电极的头皮观测 |
| $\Lambda(t)$ | 偏侧指数 |

## 公式

**第一级：LGN 时空滤波**

$$L(\mathbf{x},t) = \iint K_{\text{LGN}}(\mathbf{x}-\mathbf{x}',\,t-t')\,I(\mathbf{x}',t')\,\mathrm{d}\mathbf{x}'\mathrm{d}t' \tag{2-1}$$

$$K_{\text{LGN}}(\mathbf{x},t) = \underbrace{\Bigl[G_{\sigma_c}(\mathbf{x}) - k\,G_{\sigma_s}(\mathbf{x})\Bigr]}_{\text{空间差分高斯}}\cdot\underbrace{\frac{t}{\tau_L^2}e^{-t/\tau_L}H(t)}_{\text{因果 Gamma 时间核}} \tag{2-2}$$

差分高斯给出中心—周边拮抗的对比敏感特性，因果 Gamma 核给出 LGN 的延迟与瞬态响应。

**第二级：形状选择性响应**

每个皮层单元对偏好模板做匹配滤波，并以能量形式对相位不敏感：

$$z_j(t) = \sqrt{\Bigl(\int \mathbf{w}_j(\mathbf{x})L(\mathbf{x},t)\,\mathrm{d}\mathbf{x}\Bigr)^2 + \Bigl(\int \mathbf{w}_j^{\perp}(\mathbf{x})L(\mathbf{x},t)\,\mathrm{d}\mathbf{x}\Bigr)^2} \tag{2-3}$$

$$\mathbf{w}_j^{\perp} = \text{Hilbert}(\mathbf{w}_j),\qquad u_j(t) = \frac{z_j^2(t)}{\sigma_n^2 + \sum_{j'} z_{j'}^2(t)} \tag{2-4}$$

式 (2-4) 的除法归一化使响应只依赖特征组合的相对强度，这正是题面所述"轮廓包裹双眼、双眼位于嘴部上方"式结构判据的数学形式。

**左右镜像**：设右指三角激活的偏好模板集合为 $\{\mathbf{w}_j\}$，则左指三角激活的集合为镜像集 $\{\mathbf{w}_j^{\text{M}}\}$，$\mathbf{w}_j^{\text{M}}(\mathbf{x}) = \mathbf{w}_j(M\mathbf{x})$，$M$ 为水平镜像矩阵。这是左右差异的几何来源。

**第三级：介观集群动力学（Wilson–Cowan）**

$$\tau_E\frac{\mathrm{d}E_j}{\mathrm{d}t} = -E_j + (1-E_j)\,f_E\bigl(w_{EE}E_j - w_{EI}I_j + h_E + u_j(t)\bigr) \tag{2-5}$$

$$\tau_I\frac{\mathrm{d}I_j}{\mathrm{d}t} = -I_j + (1-I_j)\,f_I\bigl(w_{IE}E_j - w_{II}I_j + h_I\bigr),\qquad f(u) = \frac{1}{1+e^{-a(u-\vartheta)}} \tag{2-6}$$

**第四级：宏观同步（Kuramoto）**

$$\frac{\mathrm{d}\theta_n}{\mathrm{d}t} = \omega_n + \frac{K}{N}\sum_{p=1}^{N}C_{np}\sin\bigl(\theta_p(t-\tau_{np}) - \theta_n(t)\bigr) \tag{2-7}$$

$$r(t)e^{i\psi(t)} = \frac{1}{N}\sum_{j=1}^{N}e^{i\theta_j(t)} \tag{2-8}$$

**第五级：头皮观测算子**

$$y_m(t) = \sum_{n}A_{mn}\,E_n(t)\,\cos\theta_n(t) + \varepsilon_m(t),\qquad m \in \{\text{F3},\text{Fz},\text{F4}\} \tag{2-9}$$

导联场 $A_{mn}$ 随源到电极的距离单调衰减。由于前额三导在矢状方向上近乎共线且间距有限，$A_{mn}$ 构成一个空间低通算子，这正是头皮观测只能看到源的宏观汇集的数学表现。

**左右差异的形成机制**。设右指刺激的源分布为 $\{(\mathbf{x}_n, E_n^{\text{R}})\}$，左指刺激的源分布为其镜像。于是

$$y_m^{\text{R}}(t) - y_m^{\text{L}}(t) = \sum_n \bigl(A_{mn}E_n^{\text{R}}\cos\theta_n^{\text{R}} - A_{m,n^{\text{M}}}E_n^{\text{L}}\cos\theta_n^{\text{L}}\bigr) \tag{2-10}$$

当镜像源对称于中线时，Fz 位于中线，其两侧贡献相消，故 $y_{\text{Fz}}$ 对镜像差异不敏感；而 F3 与 F4 分别偏向左侧与右侧，$A_{\text{F3},n}$ 与 $A_{\text{F4},n}$ 对镜像源集合的取值互换，因此差分 $y_{\text{F4}} - y_{\text{F3}}$ 对该镜像差异最敏感。这解释了为什么偏侧特征比单导幅值更有效。

**特征表示**。由上述机制导出两个互补特征：

$$f_{\text{shape}} = \frac{1}{|W_1|}\int_{W_1}\bar y_{\text{Fz}}(t)\,\mathrm{d}t,\qquad W_1 = [80,\,250]\ \text{ms} \tag{2-11}$$

$$f_{\text{space}} = \frac{1}{|W_2|}\int_{W_2}\bigl[\bar y_{\text{F4}}(t) - \bar y_{\text{F3}}(t)\bigr]\mathrm{d}t,\qquad W_2 = [250,\,800]\ \text{ms} \tag{2-12}$$

$f_{\text{shape}}$ 编码形状在早期视觉响应中的强度，$f_{\text{space}}$ 编码镜像空间分布在偏侧导联上的投影差异。联合特征 $\mathbf{z} = [f_{\text{shape}},\, f_{\text{space}}]^{\top}$ 经线性判别分析给出左右判据

$$\delta(\mathbf{z}) = \mathbf{v}^{\top}\mathbf{z} + v_0 \tag{2-13}$$

## 约束

1. 模型各阶段的时间常数须满足尺度递增关系 $\tau_L < \tau_E < \tau_{\text{macro}}$，与微观—介观—宏观的层次一致。
2. Wilson–Cowan 方程中 $E_j, I_j \in [0,1]$ 由 $(1-E)$、$(1-I)$ 因子自动保证。
3. 序参数满足 $0 \le r(t) \le 1$。
4. 导联场权重 $A_{mn} \ge 0$ 且随源—电极距离单调不增。
5. 镜像对称性约束：左右刺激的源分布互为镜像，模型参数（除空间分布外）完全相同，避免用不同参数人为制造差异。

## 方法

**候选方法比较**。

- **候选一：纯统计学习分类器**。直接用 SVM 或随机森林对单试次波形分类。优点是实现简单，缺点是个体差异大、泛化性差，且无法解释差异的形成机制，题面明确指出这类方法"在神经性疾病诊断、治疗及脑机接口领域应用仍然有很多不确定性"。
- **候选二：纯宏观 Kuramoto 模型**。仅用相位耦合刻画。优点是有现成理论，缺点是题面已指出它"没有考虑神经元的空间分布"，而左右差异恰恰是空间分布差异，因此该模型在原理上无法解释本问的核心现象。
- **候选三：多尺度前向计算模型（本文主方法）**。串联 LGN 时空滤波、形状选择性响应、介观集群动力学、宏观同步与头皮观测五级，显式包含空间分布与镜像对称。

**主方法锁定理由**。只有候选三同时具备两点：一是显式包含形状选择性神经元的空间排列，从而能解释左右镜像刺激的差异来源；二是输出可观测的头皮电位，能与题目数据直接比较。候选一不可解释，候选二缺少空间维度。

## 验证

1. **机制预测的可检验推论**。模型预测 Fz 对镜像差异不敏感而 F4−F3 敏感。实测结果与之一致：晚期窗口的 F4−F3 偏侧特征在四个数据集上的交叉验证 AUC 为 0.492–0.618，而同期 Fz 幅值的 AUC 为 0.512–0.545。
2. **特征窗口的实测依据**。对刺激后窗口分五段扫描判别性能，早期 80–250 ms 的 Fz 幅值（0.561–0.563）与晚期 250–800 ms 的偏侧特征（0.549–0.568）分别最优，与式 (2-11)、(2-12) 的窗口设定一致。
3. **与随机水平对照**。所有特征的交叉验证 AUC 均高于 0.5，联合特征在四个数据集上达到 0.53–0.58，说明特征确实承载左右信息而非过拟合。
4. **跨被试一致性**。两个被试的记录给出同向结论，说明机制不是个体特例。
5. **模型输出的可观测性**。式 (2-9) 的输出与问题一提取的头皮响应在时间窗与导联极性上对应，可直接比较。
