# 问题三：认知宏观模型与脑电数据验证

## 目标

截取与视觉认知相关联的信号（终点为应答响应之前约 100 ms），借助问题二建立的脑电信号形成机制，并考虑信号可能同时来源于海马体与 LGN 等多个源，建立认知的宏观模型，并用题目提供的脑电信号验证该模型。题面特别提示应答不一定正确、也可能没有及时应答，因此模型不能假设"应答方向等于提示方向"，必须把认知过程与应答行为分开刻画。

## 输入

- 问题一输出的去噪分段信号与有效响应特征。
- 问题二建立的多尺度前向机制与式 (2-9) 的头皮观测算子。
- 事件时序：VisCue 标记为 0 时刻，TgtAct 标记平均出现在约 2.2–2.3 s；认知信号截取窗口取 $[-0.2,\,1.1]$ s，其终点位于应答之前约 100 ms 以上。
- 行为标签：提示方向（左靶 −1 / 右靶 +1）与应答方向（左 / 右）。

## 假设

1. 认知过程由两条通路共同承担：LGN—皮层视觉通路提供"看到什么"的直接视觉信息，海马体—前额通路提供"这是什么"的记忆对照信息。
2. 海马体通路相对视觉通路存在传导延迟 $\tau_H$ 与增益 $g_H$，增益反映记忆信号的强度；题面指出阿尔茨海默症早期表现为源于海马体的信号逐渐迟缓且微弱，对应 $\tau_H$ 增大、$g_H$ 减小。
3. 两条通路的群体活动可分别用 Kuramoto 相位方程描述，通路间通过延迟耦合项相互作用。
4. 前额叶认知区对两路信息做一致性整合，整合变量由两路序参数的加权和与符合项共同驱动。
5. 头皮观测是整合变量的空间低通投影，与问题二式 (2-9) 同构。
6. 项目一在提示阶段已知目标位置、项目二只知形状，因此项目二的记忆对照回路需要维持更长时间。

## 变量

| 符号 | 含义 |
|------|------|
| $\theta_n^{V},\theta_n^{H}$ | 视觉通路与海马体通路的振子相位 |
| $\omega_V,\omega_H$ | 两通路的固有频率 |
| $K_{VV},K_{HH},K_{VH},K_{HV}$ | 通路内与通路间耦合强度 |
| $\tau_H$ | 海马体通路传导延迟 |
| $g_H$ | 海马体通路增益 |
| $r_V(t),r_H(t)$ | 两通路的序参数 |
| $R(t)$ | 前额叶认知整合变量 |
| $\beta_V,\beta_H,\gamma$ | 视觉权重、记忆权重与符合项系数 |
| $\tau_R$ | 整合时间常数 |
| $y_m(t)$ | 电极 $m$ 的预测头皮电位 |
| $\Theta$ | 待辨识参数向量 |

## 公式

**双通路相位动力学**

$$\frac{\mathrm{d}\theta_n^{V}}{\mathrm{d}t} = \omega_V + \frac{K_{VV}}{N_V}\sum_{p}C^{V}_{np}\sin\bigl(\theta_p^{V}(t-\tau^{V}_{np}) - \theta_n^{V}\bigr) + \frac{K_{HV}}{N_H}\sum_{q}C^{VH}_{nq}\sin\bigl(\theta_q^{H}(t-\tau_H) - \theta_n^{V}\bigr) \tag{3-1}$$

$$\frac{\mathrm{d}\theta_n^{H}}{\mathrm{d}t} = \omega_H + \frac{K_{HH}}{N_H}\sum_{q}C^{H}_{nq}\sin\bigl(\theta_q^{H}(t-\tau^{H}_{nq}) - \theta_n^{H}\bigr) + \frac{K_{VH}}{N_V}\sum_{p}C^{HV}_{np}\sin\bigl(\theta_p^{V}(t) - \theta_n^{H}\bigr) \tag{3-2}$$

**序参数**

$$r_{V}(t)e^{i\psi_V(t)} = \frac{1}{N_V}\sum_{n}e^{i\theta_n^{V}(t)},\qquad r_{H}(t)e^{i\psi_H(t)} = \frac{1}{N_H}\sum_{n}e^{i\theta_n^{H}(t)} \tag{3-3}$$

**前额叶认知整合**

$$\tau_R\frac{\mathrm{d}R}{\mathrm{d}t} = -R(t) + \beta_V r_V(t) + \beta_H g_H\, r_H(t-\tau_H) + \gamma\, r_V(t)\,r_H(t-\tau_H) \tag{3-4}$$

式 (3-4) 中第三项为符合项：只有视觉信息与记忆对照信息在时间上对齐时，整合变量才获得额外增益。这正是"从记忆功能区中寻找信息对比，并激活前额叶认知功能区"的数学表达。

**头皮观测与预测**

$$y_m(t) = \sum_{s\in\{V,H\}} A_{ms}\,\rho_s(t)\cos\psi_s(t) + \varepsilon_m(t),\qquad \rho_V = r_V,\ \rho_H = g_H r_H \tag{3-5}$$

**认知信号截取**：定义认知窗口

$$W_C = [t_{\text{cue}} - 0.2\ \text{s},\ t_{\text{act}} - 0.1\ \text{s}] \tag{3-6}$$

其终点位于应答之前约 100 ms，符合题面要求。

**参数辨识**：以预测与实测的加权残差平方和为目标

$$\hat\Theta = \arg\min_{\Theta}\ \sum_{m}\sum_{t\in W_C} w(t)\bigl[y_m(t) - \bar y_m(t)\bigr]^2 + \lambda\lVert\Theta - \Theta_0\rVert^2 \tag{3-7}$$

其中 $w(t)$ 为按基线稳健尺度归一化的权重，$\lambda$ 为正则项系数，用于在有限试次下抑制过拟合。

**认知负荷指标**：定义记忆回路维持强度

$$\Phi = \frac{1}{|W_C|}\int_{W_C} g_H\, r_H(t)\,\mathrm{d}t \tag{3-8}$$

该指标越小，说明海马体来源的信号越弱，与题面所述阿尔茨海默症早期特征方向一致。

## 约束

1. $r_V, r_H \in [0,1]$ 由序参数定义自动保证。
2. $g_H > 0$，$\tau_H \ge 0$；$\tau_H$ 的上界由认知窗口长度约束。
3. 两通路耦合强度须使系统在刺激后回到稳定状态，即 $\tau_R \mathrm{d}R/\mathrm{d}t$ 项不发散。
4. 辨识参数须落在预设物理区间内，超出即判为不可辨识并记录，不强行取值。
5. 模型参数对两个被试独立辨识，禁止用一套参数拟合全部数据后宣称个体适用。

## 方法

**候选方法比较**。

- **候选一：单源宏观模型**。只用一路 Kuramoto 振子群加观测算子。优点是参数少、易辨识，缺点是无法体现题面强调的"信号可能同时来源于海马体和 LGN 等"，也无法解释项目一与项目二的差异。
- **候选二：纯现象学回归模型**。直接对头皮电位做多项式或高斯混合拟合。优点是拟合优度高，缺点是没有任何机制含义，不能回答"认知如何形成"，也无法给出可迁移的指标。
- **候选三：双源延迟耦合认知宏观模型（本文主方法）**。两路 Kuramoto 振子群加延迟耦合，经符合项整合后由观测算子投影到头皮。

**主方法锁定理由**。候选三在保持可解释性的同时容纳了题面要求的双源结构，并给出式 (3-8) 这样的可迁移临床指标。候选一缺少记忆通路，候选二缺少机制。

## 验证

1. **拟合优度**。以辨识参数生成预测信号，与实测平均响应逐点比较，报告相关系数、均方根误差与决定系数，并按被试分别报告，不做跨被试混合报告。
2. **参数可辨识性**。对每个参数做局部扰动扫描，报告目标函数曲面的曲率与参数置信区间；曲率过小的参数判为弱可辨识并如实说明。
3. **行为学分层验证**。按应答是否正确（提示方向与应答方向是否一致）分层，比较两组的模型残差与式 (3-8) 指标。项目二的提示—应答一致率仅 0.470 与 0.480，具备天然的错误应答样本，可用于分层。
4. **项目间对照**。项目一与项目二的认知窗口长度与记忆负荷不同，模型应给出方向一致但幅度不同的指标，用于检验模型是否捕捉到真实差异。
5. **与设备滤波对照**。项目二的低频慢电位被设备滤波器移除，若模型依赖该成分，则用设备滤波通道数据验证时应出现系统性失配，这一对照可检验模型是否真的在使用任务相关成分。
6. **边界与失效情形**。若 $g_H \to 0$，模型退化为单源模型，此时项目一与项目二应当不可区分，实测差异说明 $g_H > 0$。
