# 数据来源映射（data/source_map.md）

本文件逐条登记进入建模链路的数据。未在本文件登记的数据不得用于建模、绘图、正文或摘要。

## 登记口径

- 数据名称：文件或数据集的正式名称。
- 用途：在本项目中承担的具体角色。
- 来源类型：赛题附件 / 官方数据源 / 公开数据库 / 派生数据。
- 具体依据：外部链接，或明确的文件路径、附件名。
- 派生数据额外记录：上游源文件、生成脚本、处理说明。

## 数据条目

### 1. 视觉认知实验脑电数据 VisualCogA_Task-1

- 数据名称：VisualCogA_Task-1.mat
- 用途：实验项目一（A 组任务一）原始脑电记录，含 Fz/F3/F4 三导原始信号、机器去噪信号、ECG 参考通道、视觉提示标记、目标应答标记与时间戳；用于问题一的预处理与有效视觉响应提取，并为问题二、问题三提供 A 组任务一实验数据。
- 来源类型：赛题附件（2026 中国研究生数学建模竞赛 C 题随题数据）
- 具体依据：赛题/VisualCogA_Task-1.mat；项目内副本 data/raw/VisualCogA_Task-1.mat
- 数据规格：采样率 256 Hz；10 个记录通道；DataLabel=[Fz F3 F4 FzDecon F3Decon F4Decon ECG VisCue TgtAct TimeStamp]；记录时长约 874.4 s。

### 6. 事件分段派生数据

- 数据名称：data/derived/epochs_A1.npz、data/derived/epochs_A2.npz、data/derived/epochs_B1.npz、data/derived/epochs_B2.npz
- 用途：以 VisCue 标记为 0 时刻、截取刺激前 0.2 s 至刺激后 1.0 s 的单试次分段信号（三导原始通道的原始分段与去噪后分段各一套），并附带提示方向标签、应答方向标签与时间轴，供问题一的响应提取、问题二的响应分布建模与问题三的认知模型参数估计使用。
- 来源类型：派生数据
- 具体依据：由上游源文件 data/raw/VisualCogA_Task-1.mat、data/raw/VisualCogA_Task-2.mat、data/raw/VisualCogB_Task-1.mat、data/raw/VisualCogB_Task-2.mat 生成；生成脚本 数据预处理/preprocess_eeg.py；处理说明见 数据预处理/README.md 与 数据预处理/audit.json。

### 7. 有效视觉响应特征派生数据

- 数据名称：data/derived/erp_features.csv
- 用途：逐数据集、逐导联、逐条件的有效视觉响应特征表，含试次数、P300 时间窗峰值幅值与潜伏期、早期窗峰值幅值与潜伏期、分半信度、显著时间点数与伪迹抑制率；供问题一的曲线拟合结论、问题二的特征表示与问题三的模型验证使用。
- 来源类型：派生数据
- 具体依据：由上游源文件 data/raw 下四份原始记录与条目 6 的分段结果生成；生成脚本 数据预处理/preprocess_eeg.py；处理说明见 数据预处理/README.md 与 数据预处理/audit.json。

## 未使用与禁用数据声明

- 通道 4–6（FzDecon、F3Decon、F4Decon）为记录设备自带滤波器输出。按题面要求，本项目在建模链路中不直接使用这些通道，仅保留其与自建去噪结果的对照分析用途。
- 通道 7（ECG）不参与认知响应建模，仅用于核验记录系统工作正常与评估心电伪影水平。
- 本项目未引入任何外部补充数据、公开数据库数据或网络下载数据。
