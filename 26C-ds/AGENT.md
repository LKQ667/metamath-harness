本文件是华为杯 C 题论文项目的执行规约与状态留痕。任何 Agent 继续本项目前必须先读本文件。

## 一、项目基本信息

- 赛事：2026 中国研究生数学建模竞赛（华为杯）
- 题号：C 题
- 题目：服务于脑机接口与精神性疾病诊断的脑电图计算模型
- 赛事语言：中文（正文、图题、图例、坐标轴、图内文字全部中文）
- 问题数：3 问（预处理与响应提取、脑电计算模型与左右区分特征、认知宏观模型与验证）
- 正文页数目标：30 页（官方硬约束为大于 25 页，不少于 26 页）
- 全文入文图片目标总数：18 张
- 绘图模式：drawio（Draw.io 成图 + AI 概念提示词），来源 card，已锁定
- 柱状图策略：少用（仅在同源 manifest 条目写明完整 `bar_exception` 时允许）
- 子图策略：禁用子图（全部最终入文 Python 图 `panel_count=1`）
- 图型重复策略：禁止重复（重复图型类别数 G=0）
- 三维图偏好：适合时建议（每轮图型决策须评估顶刊一区中文三维图可行性）
- 优秀论文参考：开启（已发现 2 篇同题样本，已完成 10 页视觉校准）
- AI 付费生图：未授权（`confirm_paid_calls=false`），只生成概念提示词，不调用计费接口
- 运行到 PDF：是

## 二、禁止事项

- 禁止编造任何数据、结果、数值、图表、文献与代码输出。
- 禁止篡改原始数据与真实业务代码；所有清洗、滤波、去趋势、归一化与派生数据必须写入对应 `audit.json`。
- 禁止使用无法核验来源的数据与文献；每份数据必须在 `data/source_map.md` 登记，每条文献必须在 `文献/source_map.md` 登记来源链接、可信等级与支撑章节。
- 禁止把通道 4–6（FzDecon、F3Decon、F4Decon）作为建模输入直接使用（题面明确要求避免）。
- 禁止中途向用户追问、暂停或等待确认；信息不足时先核查题面、附件与项目记录，采用有依据的保守默认值并记录假设。
- 禁止用 Word 生成或转换论文；禁止跳过阶段门禁。
- 禁止跨题套用优秀论文样本内容；样本只作版式与信息密度校准，不复制其原文、公式、数据、结论与装饰符号。
- 禁止在正文中出现内部文件路径与绝对路径（提示词相对路径 `手绘图/*.md` 除外）。

## 五、阶段推进规则

1. 每完成一个阶段，运行项目内固定入口 `scripts/checks/run_stage_gate.py --stage stepN`。
2. 退出码非 0 时，完整读取该阶段 `failures_summary.json`，同一回合内修复全部失败项后重跑。
3. 只有当前阶段退出码为 0 才允许进入下一阶段。
4. 最终交付前运行 `scripts/checks/verify_delivery.py`，仅当退出码为 0 且输出 `ok: true` 才可声明完成。

## 六、绘图与结果链路规则

- Python 数据图统一使用本技能内置绘图子系统，导出 `svg + pdf + png`，并完成中文字体与论文级版式 QA。
- 每张入文图在 `figures/manifest.json` 登记 `generator`、`template_id`、`source`、`exports`、`panel_count`、`panel_chart_types`、`qa`、`paper_ready` 等字段。
- 非数据图（流程图、问题分析图、技术路线图）由 Draw.io 链路生成，保留 `.drawio` 源、SVG、PDF 与 2× PNG；概念类图只保留 2–4 份提示词。
- 绘图收束遵循“硬缺陷驱动、合格即冻结”：硬 QA 全通过且无事实错误即冻结；每次重画必须对应具体缺陷，同一根因最多 3 轮。
- 所有最终数值结果写入 `results/final_results.json`，论文、摘要、README 与逐问 `result.md` 只能引用该唯一结果源。

## 七、论文写作规则

- 主结构固定为：一、问题重述；二、模型假设与符号说明；问题一至问题三模型建立与求解；模型总结与评价；参考文献；附录。禁止新增主章节。
- 摘要使用 GMCMthesis 模板原生 `abstract` 环境，`\label{abstract:start}` 与 `\label{abstract:end}` 的编译页码跨度不超过 2，有效文字不少于 800 字。
- 正文可见论述禁止“首先、其次、然后、接着”，禁止“判决”“判定”，禁止实际字符 `•`、`☐` 与原始中点 `·`。
- 加粗只落在决定性模型名、关键判据与核心数值结论的短语上。
