# 问题一：资料预处理与有效视觉响应提取

## 目标

针对实验项目一与实验项目二，在保留反映视物形状的脑电特征的前提下，去除运动、眨眼、心电等伪影，提取 Fz、F3、F4 三个观测点位的有效视觉响应，并拟合相应曲线。题面明确指出 P300 出现在刺激后约 250–500 ms 的中央—顶区，而原始脑电不能直接显示 P300 波形，因此本问的核心是构造一个"只去除可识别非神经伪影、不破坏任务相关成分"的降噪算子，并把有效响应量化为可比较的数值特征。

## 输入

- 四份原始记录 `VisualCogA_Task-1.mat`、`VisualCogA_Task-2.mat`、`VisualCogB_Task-1.mat`、`VisualCogB_Task-2.mat`，采样率 256 Hz，10 通道，各 100 试次。
- 三导原始脑电通道 Fz、F3、F4；心电参考通道 ECG；事件通道 VisCue 与 TgtAct；时间戳通道。
- 设备自带滤波通道 FzDecon、F3Decon、F4Decon 仅作对照，按题面要求不进入建模链路。

## 假设

1. 刺激后 0–1000 ms 窗口内的脑电可分解为任务锁定成分、背景自发振荡与非神经伪影三部分，且三者在线性叠加意义上近似可分。
2. 心电伪影在各试次中波形一致、仅增益不同，因此可由 ECG 通道对齐后的中位模板刻画。
3. 运动与电极瞬变在时域表现为远高于背景的稀疏极端偏移，可通过稳健尺度判定。
4. 低频慢电位（含持续注意与准备相关成分）属于任务相关信息，不应当作伪影滤除。
5. 刺激前 0.2 s 窗口内不含任务相关成分，可用作基线。

## 变量

| 符号 | 含义 | 取值 |
|------|------|------|
| $x_{c}(t)$ | 导联 $c$ 的连续记录信号 | $\mu$V |
| $e_{c}^{(i)}(t)$ | 第 $i$ 试次、导联 $c$ 的分段信号 | $\mu$V |
| $b_{c}^{(i)}$ | 第 $i$ 试次基线 | $\mu$V |
| $T_c$ | 导联 $c$ 的心电伪迹模板 | $\mu$V |
| $g_i$ | 第 $i$ 试次的心电模板增益 | 无量纲 |
| $\sigma_c$ | 导联 $c$ 的稳健尺度 | $\mu$V |
| $A_c,\ \lambda_c$ | 导联 $c$ 的响应峰值幅值与潜伏期 | $\mu$V, ms |
| $\Lambda_c$ | 导联 $c$ 的偏侧指数 | 无量纲 |

## 公式

**分段与基线校正**

$$e_c^{(i)}(t) = x_c(t_i^{\text{cue}} + t) - \frac{1}{|B|}\int_{B} x_c(t_i^{\text{cue}} + s)\,\mathrm{d}s,\qquad B = [-0.2,\,0]\ \text{s} \tag{1-1}$$

**稳健尺度**：以中位绝对偏差定义，避免高幅伪迹支配阈值

$$\sigma_c = 1.4826\cdot \operatorname{med}\bigl|\,x_c - \operatorname{med}(x_c)\,\bigr| \tag{1-2}$$

**心电模板与条件剔除**

$$T_c(\tau) = \operatorname{med}_i\bigl\{x_c(\tau_i^{\text{R}} + \tau)\bigr\},\qquad g_i = \frac{\langle \tilde e_c^{(i)}, \tilde T_c\rangle}{\lVert \tilde T_c\rVert^2} \tag{1-3}$$

仅当同时满足 $\rho_i = \operatorname{corr}(\tilde e_c^{(i)}, \tilde T_c) > \rho_0 = 0.6$、$\max_\tau|\tilde e_c^{(i)}(\tau)| > z_0\sigma_c$（$z_0 = 6$）与 $0 < |g_i| < 3$ 时，才执行 $e_c^{(i)} \leftarrow e_c^{(i)} - g_i T_c$，其中 $\tilde{\cdot}$ 表示去均值。

**稳健软截断**：只压缩极端采样点，其余采样点原样保留

$$\hat e_c^{(i)}(t) = \operatorname{clip}\bigl(e_c^{(i)}(t),\ -z_1\sigma_c,\ z_1\sigma_c\bigr),\qquad z_1 = 10 \tag{1-4}$$

**明确不做频谱滤波**。设 $H_{\text{bp}}$ 为 0.5–30 Hz 带通算子，实测表明 $\lVert H_{\text{bp}}\hat e\rVert$ 与任务相关成分不正交，会一并移除低频慢电位，导致左右可分性显著下降（见"验证"节）。因此最终算子为

$$\mathcal{D} = \operatorname{clip}_{z_1\sigma_c}\circ \operatorname{ECGremoval} \tag{1-5}$$

**有效视觉响应与显著性**：逐时间点单样本 $t$ 检验，再用 Benjamini–Hochberg 控制错误发现率

$$t_c(t) = \frac{\bar e_c(t)}{s_c(t)/\sqrt{n}},\qquad p_c(t) = 2\,F_{t,n-1}\bigl(-|t_c(t)|\bigr) \tag{1-6}$$

$$p_{(k)} \le \frac{k}{m}\alpha,\quad \alpha = 0.05 \tag{1-7}$$

**曲线拟合**：以基线加三个高斯分量之和拟合事件相关电位

$$\hat e_c(t) = b_0 + \sum_{k=1}^{3} a_k \exp\!\left(-\frac{(t-\mu_k)^2}{2\sigma_k^2}\right) \tag{1-8}$$

参数以非线性最小二乘求解，幅值限 $|a_k| \le 500\ \mu$V，潜伏期限于各分量预设邻域，宽度限 $0.02$–$0.30$ s。

**偏侧指数**：度量左右靶条件的幅值不对称

$$\Lambda_c = \frac{A_c^{\text{R}} - A_c^{\text{L}}}{|A_c^{\text{R}}| + |A_c^{\text{L}}| + \epsilon} \tag{1-9}$$

## 约束

1. 分段窗口固定为 $[-0.2, 1.0]$ s，越界试次不进入分析。
2. 软截断只改变超出阈值的采样点，阈值内采样点逐点保持原值，保证波形形状与相位不失真。
3. 心电模板扣除必须同时满足相关性、幅度与增益三重条件，避免把脑电本身当作心电扣除。
4. 拟合参数须落在生理合理区间，拟合失败时如实记录而不填充替代值。

## 方法

**候选方法比较**。比较了七类方案：传统 0.5–30 Hz 带通加试次剔除、小波全域软阈值、低秩稀疏分解（稳健主成分分析）、参考引导小波稀疏收缩、大瞬变插值、心电模板剔除加权平均，以及本文的心电模板剔除加稳健软截断。评价采用双准则：伪迹抑制率（99 分位单试次峰值的下降比例）与视物特征保留度（早期形状特征与晚期偏侧特征联合的重复交叉验证 AUC）。

**主方法锁定理由**。带通类方案虽然把伪迹抑制率做到 0.85，但在两个项目二记录上把可分性压到 0.468 与 0.412，低于随机水平；小波全域阈值与低秩稀疏分解的伪迹抑制率不足 0.08，去噪效果有限；参考引导收缩与瞬变插值会替换整段波形，破坏了慢电位。心电模板剔除加稳健软截断只压缩极端采样点、不改变其余波形，同时把可分性保持在 0.53–0.58，因此锁定为主方法。

**求解步骤**。解析事件并分段 → 基线校正 → 心电模板估计与条件剔除 → 稳健软截断 → 逐导联逐条件计算平均响应与逐点显著性 → 三高斯分量拟合 → 输出特征表。

## 验证

1. **方案配对检验**。跨四个数据集的重复交叉验证显示，本文方案相对 0.5–30 Hz 带通方案把左右可分性提高 0.0592（$t = 4.461$，$p < 0.001$，自助法 95% 区间 $[0.0330, 0.0849]$），相对原始信号提高 0.0071（$t = 3.464$，$p = 0.001$）。
2. **伪迹抑制**。99 分位单试次峰值平均下降 0.325，四份记录的心电修正试次与截断采样点数量逐条记录在 `audit.json`。
3. **设备滤波对照**。项目二记录中原始 Fz 在刺激后 600–990 ms 的均值超过 100 µV，而设备自带滤波通道同窗口均值不足 1 µV，说明设备滤波器确实移除了任务相关低频成分，与本文"不做频谱滤波"的选择一致。
4. **行为学一致性**。项目一提示—应答一致率为 1.000 与 0.980，项目二为 0.470 与 0.480，与实验设计完全吻合，说明事件解析正确。
5. **拟合优度**。三高斯分量拟合在项目二记录上 $R^2$ 达 0.85–0.98，项目一记录为 0.33–0.87，拟合优度差异本身反映了两个项目响应强度的真实差别。
