# 问题一结果说明

## 问题目标

针对实验项目一与实验项目二，在保留反映视物形状的脑电特征的前提下去除运动、眨眼、心电等伪影，提取 Fz、F3、F4 三个观测点位的有效视觉响应，并拟合相应曲线。

## 输入数据

四份赛题原始记录，采样率 256 Hz，每份 10 通道、各 100 试次，合计 400 试次、约 3536.5 s。三导原始通道 Fz、F3、F4 进入建模链路；设备自带滤波通道 FzDecon、F3Decon、F4Decon 仅作对照。

| 记录 | 时长/s | 试次 | 提示左/右 | 提示—应答一致率 |
|------|--------|------|-----------|------------------|
| A 组项目一 | 874.4 | 100 | 54 / 46 | 1.000 |
| A 组项目二 | 899.0 | 100 | 57 / 43 | 0.470 |
| B 组项目一 | 871.1 | 100 | 48 / 52 | 0.980 |
| B 组项目二 | 891.9 | 100 | 50 / 50 | 0.480 |

## 核心假设

1. 刺激后 0–1000 ms 窗口内脑电可分解为任务锁定成分、背景自发振荡与非神经伪影三部分。
2. 运动与电极瞬变在时域表现为远高于背景的稀疏极端偏移。
3. 低频慢电位属于任务相关信息，不是伪影。
4. 刺激前 0.2 s 窗口不含任务相关成分，可作基线。

## 模型思路

分段与基线校正后，用稳健软截断压缩极端偏移，不做任何高通或带通。这一选择由双准则比较确定：伪迹抑制率与视物特征保留度必须同时满足。

## 关键公式通俗解释

- 稳健尺度用中位绝对偏差估计，避免少数高幅伪迹把阈值抬高到失效。
- 软截断把超出 10 倍稳健尺度的采样点压到阈值，阈值内的采样点逐点保持原值，因此波形形状与相位不失真。
- 有效响应用逐时间点单样本 t 检验配合 Benjamini–Hochberg 错误发现率控制筛选，避免通道乘时间的大量比较产生假阳性。
- 曲线拟合用基线加三个高斯分量之和，三个分量分别对应早期感觉成分、中期成分与晚期持续成分。
- 偏侧指数刻画左右靶条件的幅值不对称程度。

## 核心数值结果

**去噪方案的配对检验**。跨四个数据集的重复交叉验证（每种子分层五折）显示，本文方案相对 0.5–30 Hz 带通方案把左右可分性提高 0.0592（t = 4.461，p < 0.001，自助法 95% 区间 [0.0330, 0.0849]），相对原始信号提高 0.0071（t = 3.464，p = 0.001，95% 区间 [0.0032, 0.0114]）。

| 记录 | 原始信号 | 0.5–30 Hz 带通 | 带通加试次剔除 | 本文方案 |
|------|----------|----------------|----------------|----------|
| A 组项目一 | 0.5515 | 0.5135 | 0.5489 | **0.5610** |
| A 组项目二 | 0.5785 | 0.4683 | 0.4859 | **0.5811** |
| B 组项目一 | 0.5140 | 0.5791 | 0.5913 | 0.5306 |
| B 组项目二 | 0.5374 | 0.4124 | 0.4175 | **0.5372** |

传统带通在两个项目二记录上把可分性压到 0.468 与 0.412，低于随机水平。

**去噪强度扫描**。软截断阈值从 20 倍收紧到 10 倍稳健尺度时，伪迹抑制率由 0.067 升到 0.325，可分性由 0.5466 升到 0.5525；继续收紧到瞬变插值 8 倍时抑制率升到 0.340，但可分性降到 0.5235。10 倍软截断同时取得最高可分性与较强抑制。

**心电伪迹核验**。EEG 片段与心电中位模板的最大相关度为 0.35–0.45，全部低于 0.6 判定阈值，无任何试次触发扣除条件，因此不引入心电模板扣除。

**有效视觉响应**。P300 时间窗（250–500 ms）内左靶与右靶峰值幅值如下，单位 μV。

| 记录 | Fz 左/右 | F3 左/右 | F4 左/右 | 显著时间点数（Fz/F3/F4） |
|------|----------|----------|----------|--------------------------|
| A 组项目一 | −5.10 / 2.61 | −15.64 / 14.02 | 0.45 / 23.41 | 0 / 0 / 0 |
| A 组项目二 | 16.63 / 37.11 | 35.34 / 61.89 | 20.13 / 56.96 | 131 / 119 / 78 |
| B 组项目一 | −22.42 / 20.95 | −2.66 / −7.68 | 27.73 / −1.79 | 0 / 0 / 0 |
| B 组项目二 | 60.12 / 43.62 | 30.60 / 66.39 | −2.91 / 98.42 | 205 / 71 / 76 |

两个项目一记录在错误发现率控制后没有任何时间点显著，说明其视觉响应弱于背景噪声水平；两个项目二记录有 71 至 205 个显著时间点，且幅值达数十微伏。

**伪迹处理计数**。软截断采样点数与设备饱和采样点数分别为：A 组项目一 4726 与 11284，A 组项目二 580 与 4650，B 组项目一 4779 与 8912，B 组项目二 893 与 9479。项目一记录的软截断点数约为项目二的 5 至 8 倍，说明项目一受瞬变干扰更重。

**三高斯分量拟合**。决定系数在项目二记录上为 0.972 至 0.991，在项目一记录上为 0.427 至 0.867。拟合优度差异本身反映两个项目响应强度的真实差别。

## 结果解释

项目一与项目二的提示—应答一致率分别为约 1.00 与约 0.48，与实验设计完全吻合：项目一在提示阶段已知目标位置，项目二只知形状。这一差异使项目二成为分析视觉形状加工的干净条件，因为其提示后窗口不含动作准备成分。

设备自带滤波通道在项目二记录刺激后 600–990 ms 的均值不足 1 μV，而原始通道同窗口均值超过 100 μV。结合传统带通把可分性压到随机水平以下的结果，可以确认题面所述"现有处理方案在去除伪迹的同时破坏了反映视物的脑电特征"确实存在，且被破坏的正是承载视物信息的低频慢电位。

## 局限与下一问衔接

项目一记录的错误发现率控制后无显著时间点，说明本问提取的响应在项目一条件下信噪比不足，相关结论只在项目二条件下稳健。心电伪迹不显著这一结论只对当前三导联前额记录成立，换用其他导联或参考方式需要重新核验。

本问输出的去噪分段信号与有效响应特征是问题二建立多尺度计算模型、构造左右区分特征的直接输入，也是问题三辨识认知模型参数的观测目标。
