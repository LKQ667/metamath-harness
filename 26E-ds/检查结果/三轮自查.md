# 三轮全链路自查

本文在最终交付前完成三轮全链路自查，覆盖内容与数据链、论文与版式链、代码与复现链。
三轮均以项目内脚本的真实输出为唯一依据，不使用记忆或估计值。

## 第一轮：内容与数据链

### 数据链完整性

- 数据来源：全部数据来自赛题提供的 CMU-MOSEI 系列附件，登记在 `data/source_map.md`，未引入任何外部数据集与外部预训练权重。
- 唯一结果源：全部数值统一保存在 `results/final_results.json`，论文正文、摘要、各问 `result.md` 与 `README.md` 只引用该文件中的数值，不存在互相冲突的多套结果。
- 问题一：100 条样本全部完成三模态特征提取，覆盖完整性核对通过；文本、语音、视觉维度分别为 768、74、35，序列位置 50；无效数值计数为 0。
- 问题二：训练 3395 条、验证 728 条、测试 727 条，模型参数只在训练集学习、结构与阈值在验证集选择；附件3 的 30 条无标签样本只用于最终推理。
- 问题三：附件4 的 20 条样本只用于最终推理与解释产出；解释卡的每一项都能在关键证据定位文件中找到对应行。
- 数据缺失与异常：附件3 的位置 0 在语音与视觉序列中恒为全零，按文件规则记为填充位而不计入缺失区间，该处理规则已写入数据预处理说明与 `a3_missing_mask.csv`。
- 未发现编造、篡改或来源不明的数据；未发现需要报告的数据矛盾。

### 自然衔接与文风

- 自然衔接：各问章节之间用“输入来自上一问的哪一项输出、本问的输出又被下一问如何使用”承接，例如问题三的解释量直接复用问题二的门控权重，不靠“接下来”“下一节”等套话过渡。
- 句式长短变化：段落内长短句交替，判断句、条件句与数据句混排，未出现成对排比或模板化三段式。
- 括号密度：论文可见论述的括号密度低于每千字 4 组，由文风门禁自动核对通过。
- 第一人称必要性：全文仅在“本文提出/本文选择/本文采用”等确需区分自有工作与外部结论处使用第一人称，未出现叙述性第一人称。
- 机械连接词：可见论述中“首先、其次、然后、接着”均为 0 次；零容忍词“判决、判定”为 0 次。

### 图与结论的对应

- 每张入文图都对应一个明确的论证职责，图后 1 至 3 句说明现象与对当前模型或题目指标的意义。

## 第二轮：论文与版式链

- 模板身份：使用 GMCMthesis 模板（`\documentclass[bwprint]{gmcmthesis}`），封面由 `\maketitle` 生成，目录由模板原生 `\maketoc` 生成且位于摘要之后，未手写目录环境、未使用 `\tableofcontents`。
- 正文章节白名单：正文主章节依次为“问题重述”“模型假设与符号说明”“问题一模型建立与求解”“问题二模型建立与求解”“问题三模型建立与求解”“模型总结与评价”，无新增主章节。
- 废话主章节清理：候选方法比较、可复现性说明、边界讨论、问题衔接、运行顺序等内容全部并入对应“问题 X 模型建立与求解”章节或附录说明，未作为独立主章节。

### 摘要页
