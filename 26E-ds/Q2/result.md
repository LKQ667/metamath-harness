# 问题二结果说明

## 问题目标

针对局部时段模态信息缺失的复杂场景，构建鲁棒性多模态情感预测模型，在局部模态信息不完整的条件下稳定
输出情感极性与情感强度预测，分析缺失模态类型、缺失位置、缺失时长对预测性能的影响规律，并对附件 3 的
30 条无标签样本完成推理。

## 输入数据

- 附件 2 对齐版：训练 3395 条、验证 728 条、测试 727 条，文本 768 维、语音 74 维、视觉 35 维、50 个位置。
- 附件 3 对齐版：30 个 pkl，语音与视觉平均缺失比例约 0.667 与 0.670，文本约 0.557。

## 核心假设

1. 缺失表现为序列上连续区间的特征值全零，缺失区间可从数值本身反演，不需要额外掩码文件。
2. 训练集缺失模式与专项测试集同源，可用训练集上随机施加的缺失区间近似专项测试集的缺失分布。
3. 缺失区间内信息确实不可用，禁止插值、外推或跨样本复制来补全缺失值参与预测。
4. 情感极性三分类与情感强度回归共享同一条时序表示。
5. 语音与视觉可能在同一时段同时缺失，缺失事件不假定相互独立。

## 模型思路

两阶段流程。第一阶段为单模态时序编码：线性投影 + 层归一化 + 双向 GRU + 掩码注意力池化，文本、语音、
视觉各训练一个编码器并在后续冻结。第二阶段为缺失感知融合：可信度门控由编码内容、可用性掩码与模态嵌入
共同决定，并与掩码相乘形成硬约束；随后做掩码归一化融合、跨模态自注意力与位置聚合，最后接三分类与回归
双头；另加一条跨模态交互支路，把各模态的时序摘要与可用性摘要拼成全局描述向量。训练目标为类别加权交叉
熵加 Huber 回归。

## 关键公式通俗解释

门控权重 $g^{m}_{i,k}=\sigma(f_\theta([\mathbf{h}^{m}_{i,k};s^{m}_{i,k};\mathbf{e}_m]))$ 表示“这个位置
这个模态有多可信”，再乘掩码得到 $\tilde{g}$，缺失位置的权重恒为 0，缺失信息不进入任何融合与聚合。
融合按可用门控权重做加权平均，分母只统计可用权重，因此缺失多少模态都不会把表示缩放到 0 附近。
位置聚合权重 $\beta$ 同样只在可用位置上归一化。类别权重 $w_c=N/(3N_c)$ 用于缓解中性类样本偏少的问题。

## 结果解释

消融结果显示：去掉可信度门控后强度误差从 0.6418 升到 0.6480，去掉跨模态注意力后升到 0.6448，
简单平均融合与仅文本分别升到 0.6615 与 0.6616，张量外积融合升到 0.6649，仅语音与仅视觉分别升到
0.9479 与 0.9168。这说明门控与注意力各自都有贡献；同时要注意，主模型在无缺失的极性准确率（0.5632）
并不高于简单平均融合（0.5907）与仅文本（0.5810），而三者的强度误差顺序恰好相反（0.6418 < 0.6615、
0.6616），因此本文的结论是：融合结构主要改善强度回归的稳定性与缺失条件下的退化幅度，而不是无条件提高
无缺失时的极性准确率。缺失率扫描显示全模态同时缺失到 0.7 时准确率从 0.5632 降到 0.5563、误差从
0.6418 升到 0.6674；单模态缺失中仅缺失文本的误差增长最快（0.6418 → 0.6649），仅缺失语音与仅缺失视觉
的误差几乎不变（0.6394–0.6438 与 0.6417–0.6440），说明文本是最关键的模态、语音与视觉在本文特征下
贡献有限。缺失位置×时长的响应面显示误差随时长单调增长，长度为 25 的连续缺失下文本前段缺失的误差最高
（0.6724），中段最低（0.6522）。附件 3 推理给出 1 条负向、9 条中性、20 条正向，强度预测标准差 0.1951，
模型在缺失场景下仍给出有区分度的输出而不是塌缩到单一取值。

## 局限与下一问衔接

本问的局限有四点：一是编码器先独立训练再冻结，未与融合模块联合微调，融合增益受限；二是附件 3 只提供
BERT 词元编号而不提供连续文本表示，文本通道只能用附件 2 中最相似的连续表示作为代理，精确匹配数为 0、
相似度均值为 0.5，因此附件 3 的文本通道带有代理误差，这一点在论文中已明确写出；三是语音与视觉编码器
自身性能较弱，限制了融合上限；四是缺失施加依赖随机种子，虽然固定种子可复现，但与真实缺失分布仍有差异。
下一问在同一套编码与融合结构上加入模态级注意力、位置级注意力与逐位置模态贡献三层解释，并把关键证据
时间位置回看到原始文本、语音时段与视觉关键帧。
