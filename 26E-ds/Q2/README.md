# 问题二：模态信息缺失条件下的情感预测建模与验证

## 一、问题目标

针对局部时段模态信息缺失的复杂场景，构建鲁棒性多模态情感预测模型，在局部模态信息不完整的条件下
稳定输出情感极性与情感强度预测，并分析缺失模态类型、缺失位置、缺失时长对预测性能的影响规律；
最后对附件 3 的无标签测试样本完成推理并提交预测结果文件。

## 二、输入数据

- 附件 2 对齐版 aligned_50.pkl：训练 3395 条、验证 728 条、测试 727 条，三模态特征维度为文本 768、
  语音 74、视觉 35，序列位置 50。模型参数只在训练集上学习，结构、超参数与决策阈值在验证集上选择。
- 附件 3 对齐版 30 个 pkl：无标签专项测试集，语音与视觉平均缺失比例约 0.667 与 0.670，文本约 0.557，
  用于最终推理预测与缺失规律分析。
- 附件 2 未对齐版：作为对齐规则的独立时序对照，用于核对对齐版与未对齐版在同一输入接口下的一致性。

## 三、核心假设

1. 缺失表现为序列上连续区间的特征值全零，缺失区间的位置可从数值本身反演，不需要额外的掩码文件。
2. 训练集的缺失模式与专项测试集同源，因此可以用训练集上随机施加的缺失区间近似专项测试集的缺失分布。
3. 缺失区间内的信息确实不可用，禁止用插值、外推或跨样本复制来"补全"缺失值参与预测；模型只能依据
   可用位置与掩码本身作推断。
4. 情感极性三分类与情感强度回归共享同一条时序表示，两个任务互为辅助。
5. 语音与视觉可能在同一时段同时缺失，缺失事件不假定相互独立。

## 四、符号与变量

| 符号 | 含义 |
|---|---|
| $i$ | 样本序号 |
| $k$ | 序列位置，$k=0,\dots,49$ |
| $m\in\{\mathrm{txt},\mathrm{aud},\mathrm{vis}\}$ | 模态标识 |
| $\mathbf{h}^{m}_{i,k}$ | 第 $i$ 个样本第 $m$ 模态第 $k$ 个位置的编码表示 |
| $s^{m}_{i,k}\in\{0,1\}$ | 可用性掩码，1 表示该位置可用 |
| $g^{m}_{i,k}\in(0,1)$ | 可信度门控权重 |
| $\alpha^{m}_{i}$ | 第 $m$ 模态的整体作用权重 |
| $\mathbf{z}_i$ | 融合后的样本表示 |
| $y^{\mathrm{cls}}_i$、$y^{\mathrm{reg}}_i$ | 情感极性标签与连续情感强度 |
| $\rho$ | 缺失率，缺失位置数占总位置数的比例 |

## 五、公式与约束

**单模态时序编码。** 先做线性投影与层归一化，再经双向门控循环单元得到时序表示：

$$\mathbf{u}^{m}_{i,k}=\mathrm{GELU}\big(\mathrm{LN}(W^{m}_p\mathbf{x}^{m}_{i,k})\big),\qquad
\mathbf{h}^{m}_{i}=\mathrm{BiGRU}^{m}(\mathbf{u}^{m}_{i}),$$

其中 $\mathbf{h}^{m}_{i}\in\mathbb{R}^{L\times d}$。

**可信度门控。** 门控由编码内容、可用性掩码与模态身份共同决定：

$$g^{m}_{i,k}=\sigma\Big(f_{\theta}\big([\mathbf{h}^{m}_{i,k};\ s^{m}_{i,k};\ \mathbf{e}_m]\big)\Big),\qquad
\tilde{g}^{m}_{i,k}=g^{m}_{i,k}\,s^{m}_{i,k},$$

$\mathbf{e}_m$ 为模态嵌入。掩码相乘是硬约束：缺失位置的门控权重恒为 0，缺失信息不进入融合。

**掩码归一化融合与跨模态注意力。** 以可用门控权重为分母做加权平均，再对融合序列做自注意力：

$$\mathbf{z}^{\mathrm{fuse}}_{i,k}=\frac{\sum_m \tilde{g}^{m}_{i,k}\,W^{m}_f\mathbf{h}^{m}_{i,k}}
{\max\big(\sum_m \tilde{g}^{m}_{i,k},\ \epsilon\big)},\qquad
\mathbf{Z}_i=\mathrm{LN}\Big(\mathbf{z}^{\mathrm{fuse}}_i+\mathrm{MHA}(\mathbf{z}^{\mathrm{fuse}}_i)\Big),$$

其中自注意力用"全部门控权重为零"作为键掩码，保证填充位置不参与注意力。

**位置聚合与目标函数。** 位置权重由可学习查询打分后按可用位置归一化：

$$\beta_{i,k}=\frac{s_{i,k}\exp(q^\top \phi(\mathbf{Z}_{i,k}))}{\sum_{k'} s_{i,k'}\exp(q^\top \phi(\mathbf{Z}_{i,k'}))},\qquad
\mathbf{z}_i=\sum_k \beta_{i,k}\mathbf{Z}_{i,k},$$

$$\mathcal{L}=\underbrace{-\sum_{c=1}^{3} w_c\, y^{\mathrm{cls}}_{i,c}\log \hat{p}_{i,c}}_{\text{类别加权交叉熵}}
+\lambda\underbrace{\mathrm{Huber}\big(y^{\mathrm{reg}}_i-\hat{y}^{\mathrm{reg}}_i\big)}_{\text{强度回归}},\qquad
w_c=\frac{N}{3N_c},$$

$N_c$ 为第 $c$ 类的样本数，$\lambda=1$。

**约束条件。** 一是缺失约束 $\tilde{g}^{m}_{i,k}=0$ 当 $s^{m}_{i,k}=0$；二是归一化约束
$\sum_m \tilde{g}^{m}_{i,k}\in\{0,1,2,3\}$ 且分母不为零；三是阈值约束：三分类决策阈值只在验证集上选择；
四是数据约束：训练、验证与专项测试必须使用同一特征版本与同一输入接口。

## 六、方法

主方法为上述可信度门控加跨模态注意力的鲁棒融合模型，共享编码维度 $d=192$。候选方法比较：

- 简单平均融合：对可用模态逐位置等权平均，是缺失场景下最常见的朴素做法，作为下界对照。
- 张量外积融合：把三模态压缩后做两两与三阶外积，表达力强但参数多，在缺失条件下容易过拟合。
- 低秩多模态融合：用模态因子分解降低外积维度，参数少但缺失时因子共享会引入偏差。
- 固定权重融合（无门控）：保留注意力但去掉可信度门控，用于隔离门控的贡献。
- 无注意力融合：保留门控但去掉跨模态自注意力，用于隔离注意力的贡献。
- 单模态对照：只输入文本、语音或视觉之一，用于说明多模态融合的必要性。

训练策略比较四种缺失施加方案：不使用缺失增强、轻度增强（缺失率 0.05–0.30）、重度增强
（0.10–0.60）与课程式增强（缺失率随训练轮次从 0.05 线性升到 0.55）。以验证集强度回归的平均绝对误差
为主选择准则，选取最优策略训练最终模型。

## 七、验证设计

1. 基础性能：在验证集与测试集上报告情感极性准确率与宏平均 F1、情感强度平均绝对误差与皮尔逊相关系数。
2. 消融实验：逐项替换融合结构，核对门控与注意力各自的贡献。
3. 缺失率规律：对全模态同时缺失以及单模态缺失，扫描缺失率 0.0–0.7，每个缺失率重复 3 次随机缺失施加，
   报告均值与标准差。
4. 缺失位置规律：在序列前段、中段、后段分别施加长度为 5、10、15、20、25 的连续缺失窗口，比较性能下降。
5. 缺失时长与位置的联合规律：在位置×时长网格上计算强度回归误差，形成响应面。
6. 附件 3 推理：输出全量预测结果，并逐样本统计各模态有效位置数与作用程度。
