# 手绘图目录说明

本目录存放按项目锁定绘图模式（AI 全自动绘图）生成的非数据类插图与可追溯提示词。

## 产物清单

| 文件 | 类型 | 说明 |
|---|---|---|
| `技术路线图提示词.md` | 提示词 | 三阶段递进式建模框架的技术路线图提示词，对应成图 `技术路线图.png` |
| `特征提取流程图提示词.md` | 提示词 | 问题一三通道特征提取与对齐流程图提示词，对应成图 `特征提取流程图.png` |
| `鲁棒融合原理图提示词.md` | 提示词 | 问题二缺失感知融合机制原理图提示词，对应成图 `鲁棒融合原理图.png` |

## 与 AI 成图上限的对应关系

卡片锁定 `ai_image_limit=4`，本项目实际生成 3 张 AI 成图（原理图 1 张、流程与技术路线图 2 张），
未超出上限，且每份提示词与 manifest 中一个且仅一个 AI 条目一一对应。

## 说明

- 每份提示词只包含三个顶层区块：服务段落、生成图片的提示词、硬约束。
- 图内可见文字全部为简体中文；不渲染数值、公式、变量与流程管理类词汇。
- 提示词明确引用本 skill 内置参考图组 `assets/reference-pictures/`，并写明借鉴点与不复制声明。
- 成图必须是可严格解码的 PNG，尺寸不低于 1200×800；内容一致性、中文文字、符号公式、裁切、
  清晰度、单栏与双栏缩印、论文回填检查全部通过后才标记 `paper_ready=true`。
