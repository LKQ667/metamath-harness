# 灵敏度分析结果说明

## 问题目标

对问题二的鲁棒融合模型做参数敏感度分析，回答两个问题：一是缺失率、缺失区间长度、缺失区间数与门控阈值
这四类缺失相关参数中，哪一个对预测性能的影响最大；二是当文本与语音同时缺失时，稳健得分如何随两模态缺失率
联合变化。

## 输入数据

- `Q2/cache/encoded_sequences.npz`：问题二冻结编码器缓存的三模态编码序列与验证集标签。
- `Q2/results/robust_model.pt`：问题二最终鲁棒模型参数。
- 验证集 728 条样本，模型参数与结构均不再更新，只做输入扰动下的性能扫描。

## 核心假设

1. 敏感度分析只在验证集上进行，不接触训练集与专项测试集。
2. 参数扰动通过“在编码序列的连续区间上置零并同步把掩码置零”实现，与问题二的缺失定义完全一致。
3. 所有评估共用同一组预生成的缺失区间池与同一组参数抽样，保证方差分解只反映参数变化，不掺入额外随机性。
4. 缺失率、区间长度与区间数在实现上取整，因此区间数与门控阈值在部分取值下输出相同，这属于模型在该参数上
   的真实不敏感，不做平滑或插值掩盖。

## 模型思路

局部敏感度采用端点效应法：固定其余参数，把目标参数分别取上下界，记录强度平均绝对误差的变化区间，
区间越长表示影响越大；分别在“无缺失基线”和“三模态均缺失 35% 基线”两种情形下各做一次，用于区分
“参数本身敏感”与“只有在已存在缺失时才敏感”。全局敏感度采用联合扫描：在文本缺失率与语音缺失率的
7×7 网格上计算稳健得分，形成响应面，并给出稳健得分随文本缺失率的退化曲线与不同语音缺失率下的取值区间。

## 关键公式通俗解释

稳健得分定义为模型预测置信度乘以一个惩罚因子：
$\text{score}=\overline{\hat{p}\cdot(1-0.5\cdot\mathbb{1}[\hat{p}<\theta])}$，其中 $\hat{p}$ 为最大类
概率、$\theta$ 为门控阈值。它的含义是：既要置信度高，又不能在阈值以下“勉强下结论”。端点效应法中，
某参数的影响幅度为该参数取上下界时误差最大值与最小值之差，幅度越大说明该参数越关键。

## 运行命令

```bash
python 灵敏度分析/run_sensitivity.py --base-samples 120
python 灵敏度分析/make_figures.py
```

## 结果解释

在“三模态均缺失 35%”的基线下，影响幅度最大的两个参数是语音缺失率（0.010609）与文本缺失率
（0.008101），其次是单区间最大长度（0.004032）与视觉缺失率（0.003278），缺失区间数上限只有 0.000504，
可信度门控阈值的影响幅度为 0。结论有三层：第一，缺失“有多少”比缺失“怎么分布”更重要，因为三个缺失率
参数的幅度都大于区间长度与区间数；第二，门控阈值不影响输出，说明模型的最大类概率在验证集上几乎全部高于
0.95，阈值在 0.05–0.95 内不产生惩罚差异；第三，缺失区间数不敏感是因为在固定缺失率下，区间数从 1 增到 5
只是把同样的缺失总量拆得更碎，而模型的门控是按位置独立作用的，对“碎”不敏感。在无缺失基线下，三个缺失率
参数之外的所有参数影响幅度都为 0，说明这些参数只有在已存在缺失时才起作用。联合响应面显示稳健得分随两模态
缺失率同时上升而单调下降，从 0.9478 降到 0.9360；文本缺失率单独上升时稳健得分从 0.9473 单调降到 0.9373，
且在文本缺失率 10% 附近下降最快（0.9473 → 0.9414），提示文本通道在轻度缺失时就已经明显削弱模型置信度。

## 局限与下一问衔接

本分析的局限有三点：一是稳健得分同时受置信度与阈值惩罚影响，与强度误差的口径不同，两类指标不能直接比较
大小；二是参数在实现上取整，导致区间数与门控阈值出现零影响幅度，这是离散化效应而非严格意义上的不敏感；
三是联合响应面只扫描文本与语音两个模态，未做三模态三维网格，因为 7×7×7 的评估成本超出本项目的单机预算。
本分析为问题二的模型评价提供参数层面的依据，结论已并入论文“模型总结与评价”章节。
