# 问题三：可解释性情感预测建模与验证

## 一、问题目标

针对三模态信息完整但决策依据难以追溯的场景，构建可解释性多模态情感预测模型。模型在给出情感极性
与情感强度预测的同时，以可量化、可复核的方式说明本次判断主要依据了哪些输入信息，包括不同模态在当前
样本中的作用差异、对预测起主要作用的模态，以及各模态中与判断密切相关的局部片段；关键证据必须能对应
到原始文本片段、语音时段或视觉关键帧。

## 二、输入数据

- 附件 2 对齐版 aligned_50.pkl：模型参数只在训练集上学习，解释结构的选择在验证集上完成。
- 附件 4 对齐版 20 个 pkl 与配套 20 个 mp4：三模态信息完整，用于最终推理、解释产出与证据回看。
  视频时长由 ffprobe 实测，用于把对齐栅格位置换算为真实时间窗与关键帧号。

## 三、核心假设

1. 对齐版特征的三模态共享同一条时间轴，50 个位置在片段时长内均匀分布，因此位置可线性换算为时间窗。
2. 模态级作用权重与位置级重要性可以分解：样本级判断由"模态作用权重"与"位置重要性"的乘积结构共同决定。
3. 附件 4 只提供 BERT 词元编号而不提供连续文本表示，因此文本通道按词元编号在附件 2 训练集中匹配
   连续表示；匹配规则与命中情况在结果中如实登记。
4. 证据定位的有效性可以用删除实验量化：删除模型认为最重要的位置后置信度的下降应显著大于随机删除。
5. 解释只描述模型在当前样本上的证据分布，不代表情感产生的因果机制。

## 四、符号与变量

| 符号 | 含义 |
|---|---|
| $\mathbf{h}^{m}_{i,k}$ | 第 $i$ 个样本第 $m$ 模态第 $k$ 个位置的编码表示 |
| $s^{m}_{i,k}$ | 可用性掩码 |
| $\mathbf{p}^{m}_i$ | 第 $m$ 模态的注意力池化表示 |
| $\alpha^{m}_i$ | 第 $m$ 模态的作用程度，$\sum_m \alpha^{m}_i=1$ |
| $\mathbf{Z}_{i,k}$ | 融合后的第 $k$ 个位置表示 |
| $\beta_{i,k}$ | 第 $k$ 个位置的重要性，$\sum_k \beta_{i,k}=1$ |
| $c^{m}_{i,k}$ | 第 $m$ 模态在第 $k$ 个位置对判断的贡献 |
| $\mathcal{T}_i(K)$ | 第 $i$ 个样本重要性最高的前 $K$ 个位置集合 |

## 五、公式与约束

**模态级注意力。** 每个模态先做掩码注意力池化得到模态表示，再由模态查询打分并归一化：

$$\mathbf{p}^{m}_i=\sum_k \frac{s^{m}_{i,k}\exp(q_m^\top \psi(\mathbf{h}^{m}_{i,k}))}
{\sum_{k'} s^{m}_{i,k'}\exp(q_m^\top \psi(\mathbf{h}^{m}_{i,k'}))}\,\mathbf{h}^{m}_{i,k},\qquad
\alpha^{m}_i=\frac{\exp(w^\top \mathbf{p}^{m}_i)}{\sum_{m'} \exp(w^\top \mathbf{p}^{m'}_i)} .$$

$\alpha^{m}_i$ 就是"不同模态在当前样本中的作用差异"，取值越大表示该模态对本次判断越关键。

**位置级重要性。** 融合表示经位置查询打分后按可用位置归一化：

$$\mathbf{Z}_{i,k}=\Phi\big([\mathbf{h}^{\mathrm{txt}}_{i,k};\mathbf{h}^{\mathrm{aud}}_{i,k};\mathbf{h}^{\mathrm{vis}}_{i,k}]\big),\qquad
\beta_{i,k}=\frac{s_{i,k}\exp(v^\top \mathbf{Z}_{i,k})}{\sum_{k'} s_{i,k'}\exp(v^\top \mathbf{Z}_{i,k'})} .$$

$\beta_{i,k}$ 就是"哪些局部片段与判断密切相关"的量化形式。

**逐位置模态贡献与证据集。** 定义

$$c^{m}_{i,k}=\alpha^{m}_i\cdot \frac{s^{m}_{i,k}\exp(q_m^\top \psi(\mathbf{h}^{m}_{i,k}))}
{\sum_{k'} s^{m}_{i,k'}\exp(q_m^\top \psi(\mathbf{h}^{m}_{i,k'}))},\qquad
\mathcal{T}_i(K)=\operatorname*{arg\,top\text{-}K}_{k}\ \sum_m c^{m}_{i,k}.$$

$\mathcal{T}_i(K)$ 给出前 $K$ 个关键证据位置，按 $\tau_k=(k+0.5)D_i/L$ 换算为时间窗，再乘帧率得到视觉关键帧。

**目标函数与约束。** 目标函数与问题二同构（类别加权交叉熵 + Huber 回归）。约束为
$\sum_m \alpha^{m}_i=1$、$\alpha^{m}_i\ge 0$、$\sum_k \beta_{i,k}=1$，且缺失位置的 $\beta_{i,k}=0$。

**证据定位有效性判据。** 以删除实验的置信度落差衡量：

$$\Delta_{\mathrm{top}}(K)=\frac{1}{N}\sum_i\Big(\hat{p}_i(\varnothing)-\hat{p}_i\big(\mathcal{T}_i(K)\big)\Big),\qquad
\Delta_{\mathrm{rand}}(K)=\frac{1}{N}\sum_i\Big(\hat{p}_i(\varnothing)-\hat{p}_i\big(\mathcal{R}_i(K)\big)\Big),$$

$\mathcal{R}_i(K)$ 为同规模的随机位置集。定位增益 $\Delta_{\mathrm{top}}-\Delta_{\mathrm{rand}}>0$ 说明
模型给出的证据位置确实比随机位置更关键。

## 六、方法

主方法为模态级注意力 + 位置级注意力 + 逐位置模态贡献的三层可解释融合模型。候选方法比较：

- 梯度归因（Grad-CAM 类）：对时序输入求梯度得到重要性，实现简单但梯度噪声大、对离散缺失掩码不敏感。
- 加性归因（Shapley 类）：理论性质好但需要对每个位置重复前向，样本级解释代价高，不适合 20 条样本
  的逐样本全量解释与可复核要求。
- 注意力归因：直接读取模型内部的模态权重与位置权重，代价低、可复现、可逐样本核对，因此选为主方法。

为防止注意力权重退化为常数，模型在训练时随机施加缺失，使模态注意力必须在不同可用性条件下重新分配；
同时用删除实验作为外部核对，避免"注意力好看但无效"的情况。

## 七、验证设计

1. 基础性能：验证集与测试集上的情感极性准确率、宏平均 F1、情感强度平均绝对误差与皮尔逊相关系数。
2. 解释一致性：逐类别统计模态作用程度均值，核对不同极性下的模态作用差异是否符合数据特征。
3. 证据定位有效性：对 $K=1,3,5,10$ 做删除实验，比较删除最重要位置与删除随机位置的置信度落差。
4. 错误归因：取验证集强度回归误差最大的样本，检查其模态作用分布与误差的关系。
5. 附件 4 全量解释：输出每条样本的预测、模态作用程度、主要参考模态、关键证据位置与时间窗、视觉关键帧，
   并把关键证据回看至原始视频的对应时间位置。
