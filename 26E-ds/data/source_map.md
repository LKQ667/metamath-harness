# 数据来源映射

本文件逐条记录本项目使用的每一份数据：数据名称、用途、来源类型与具体依据。凡未在本表登记的数据，不得进入建模、图表或论文正文。

## 一、赛题官方提供数据（唯一数据来源）

赛题《复杂场景下多模态情感预测的数学建模与算法设计》明确规定：本题所有建模任务均以赛题提供的 CMU-MOSEI 系列数据为唯一数据来源，不得引入其他任何公开或私有情感数据集参与模型训练、微调、参数优化、阈值选择或结果统计。本项目严格执行该约束。

| 数据名称 | 用途 | 来源类型 | 具体依据 |
|---|---|---|---|

## 二、本项目派生的中间与结果数据

派生数据一律保留上游源文件与生成脚本，可完全重放。

| 数据名称 | 用途 | 来源类型 | 具体依据（上游源文件 + 生成脚本 + 处理说明） |
|---|---|---|---|

| `data/raw/label_a2.csv` | 附件2 标注表的无损 CSV 副本 | 派生数据（格式转换，无内容修改） | 上游：`赛题/E题数据/E题数据/附件2-数据集特征文件/label.xlsx`；生成脚本：`数据预处理/prepare_data.py` |
| `data/raw/a1_media_inventory.csv` | 附件1 每条样本的媒体文件存在性、时长、采样信息清点 | 派生数据（ffprobe 元数据探测） | 上游：附件1 的 100 个 mp4 与 label-100.xlsx；生成脚本：`数据预处理/prepare_data.py`；处理说明：调用 ffprobe 读取时长/帧率/声道，不做内容改写 |
| `data/processed/mosei_aligned.npz` | 附件2 对齐版三模态特征与标签的紧凑数组副本 | 派生数据（数组重排） | 上游：`aligned_50.pkl`；生成脚本：`数据预处理/prepare_data.py`；处理说明：仅按 train/valid/test 分键导出 float32 数组，不缩放、不改标签 |
| `data/processed/a3_missing_mask.csv` | 附件3 每个样本每个模态的缺失区间清单与有效长度 | 派生数据（掩码反演） | 上游：附件3 对齐版 30 个 pkl；生成脚本：`数据预处理/prepare_data.py`；处理说明：按“某序列位置在所有特征维度上取值全为 0”反演缺失掩码，位置 0 的全零按文件规则记为填充位不计入缺失 |
| `data/processed/a4_aligned.npz` | 附件4 对齐版三模态特征、样本编号与原始转写文本 | 派生数据（数组重排） | 上游：附件4 对齐版 20 个 pkl；生成脚本：`数据预处理/prepare_data.py` |
| `data/processed/eda_summary.json` | EDA 全部统计量（规模、缺失、异常、分布、相关性） | 派生数据（统计汇总） | 上游：上述全部原始与中间数据；生成脚本：`数据预处理/prepare_data.py` |

| 问题一自生成 100 条样本三模态时序特征文件 | 问题一要求的可复现核心材料 | 派生数据（特征提取） | 上游：附件1 的 100 个 mp4 与 label-100.xlsx；生成脚本：`Q1/extract_features.py`；处理说明：ffmpeg 解复用 → 音频对数梅尔谱统计、视频帧颜色与运动统计、文本分词与哈希词袋表示 → 统一 50 位置时间栅格对齐，全部参数写入 `Q1/feature_config.json` |

## 三、外部数据与外部文献

- 外部新增数据：无。本项目未引入任何赛题之外的数据集，未下载任何外部语料、音频或视频。
- 外部文献：见 `文献/source_map.md`，逐条登记 bibkey、来源链接、可信等级与支撑章节。
- 预训练模型权重：本项目未下载或使用任何外部预训练模型权重；文本、语音、视觉三模态表示均由本项目脚本在赛题提供的数据上确定性计算得到。
