# 数据预处理与探索性分析

## 原始输入

- `赛题/E题数据/E题数据/附件1-数据集原始多模态样本/MOSEI数据集部分原始视频-100条/`：
  37 个 video_id 子文件夹、100 个 clip_id.mp4 与标注表 label-100.xlsx。
- `赛题/E题数据/E题数据/附件2-数据集特征文件/`：aligned_50.pkl、unaligned_50.pkl 与 label.xlsx。
- `赛题/E题数据/E题数据/附件3-模态缺失特征样本/`：对齐版本 30 个 pkl、未对齐版本 30 个 pkl。
- `赛题/E题数据/E题数据/附件4-可解释专项视频样本与特征文件/`：对齐版本 20 个 pkl 与 20 个 mp4。

原始样本与标签一律保持只读，不做任何替换、增补、删除或修改。

## 处理规则

1. 标注表 xlsx 转为 UTF-8-SIG 的 csv 副本，逐行逐列校验一致，不修改任何取值。
2. 附件 1 的每个 mp4 用 ffprobe 读取容器时长、视频编解码与分辨率、音频编解码与采样率、声道数，
   写入媒体清点表；探测失败的样本如实登记，不做人工补齐。
3. 附件 2 对齐版的三模态特征与标签按 train/valid/test 导出为 float32 紧凑数组，不缩放、不改标签。
4. 附件 3 的缺失掩码按“某序列位置在所有特征维度上取值全为 0”反演；位置 0 在附件 2、附件 3 的
   语音与视觉序列中同样恒为全零，因此位置 0 的全零按文件规则记为填充位，不计入缺失区间。
   同时记录附件 3 中语音与视觉缺失区间是否完全一致。
5. 附件 4 对齐版三模态特征导出为 float32 紧凑数组，保留样本编号。
6. 全部统计量写入 `data/processed/eda_summary.json`。

## EDA

- 规模：附件 1 共 100 条样本、37 个视频标识，片段时长 2.257–29.288 秒（均值 7.875 秒、中位数 6.722 秒），
  转写文本平均 19.3 个英文词（5–65 词）；附件 2 共 4850 条样本，训练 3395、验证 728、测试 727。
- 变量类型：附件 1 为文本转写与连续/离散情感标签；附件 2、附件 4 为三模态数值特征张量；
  附件 3 为带缺失掩码的三模态数值特征张量。
- 缺失值：附件 2 语音与视觉序列存在大量全零位置（训练集平均有效位置 22.63 与 21.39，共 50 个位置），
  文本序列 50 个位置全部非零；附件 3 的语音与视觉平均缺失比例分别约 0.667 与 0.670，文本约 0.557。
- 异常值：语音第 0 维量纲为 0–500，与其余维度相差三个数量级，属量纲差异而非错误值，
  标准化时需单独处理；其余维度无越界记录。
- 重复值：附件 2 样本编号唯一，无重复样本。
- 分布：训练集连续情感强度均值 0.166、标准差 1.115、偏度 −0.322，取值为 [−3, 3] 的离散格点；
  三分类计数为负向 967、中性 758、正向 1670，中性占比 22.3%，存在明显类别不平衡。
- 相关性：训练集样本级均值特征之间的相关系数为文本–语音 −0.682、文本–视觉 0.557、语音–视觉 −0.608；
  三模态均值与连续情感强度的线性相关均较弱（|r| < 0.11），说明情感信息主要存在于时序局部结构而非全局均值，
  这一点直接决定了后续必须使用时序编码而不是全局池化。

## 结论

1. 数据规模与划分完整，可直接用于训练、验证与专项测试；附件 1 的 100 条样本媒体文件全部存在且可解码。
2. 三模态有效长度差异显著，语音与视觉平均仅约 22 个位置有效，说明“局部时段模态不可用”是数据的固有特征，
   问题二的鲁棒建模必须处理这种局部缺失，而不能假设模态整段可用或整段缺失。
3. 连续情感强度落在 [−3, 3] 的离散格点上、类别分布不平衡，回归与分类任务需要分别设计目标函数与评价口径。
4. 全局均值特征与情感强度几乎不相关，时序局部结构才是主要信息载体，因此后续模型一律采用时序编码 + 注意力聚合。
5. 语音第 0 维量纲异常，标准化必须按维度进行并单独处理该维，否则会主导距离度量。
