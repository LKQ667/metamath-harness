# 问题一：多模态情感特征提取与时序对齐的数学建模

## 一、问题目标

基于附件 1 的 100 条原始视频，建立文本、语音、视觉三模态情感特征提取与时序对齐的数学模型，
明确原始样本的处理流程、各模态情感特征的定义与提取方法、跨模态时序对齐的规则与实现逻辑，
并产出满足三项要求（样本覆盖完整性、时序组织可核验性、方法合理性与可复现性）的自生成特征文件。

## 二、输入数据

- 附件 1 原始多模态样本：37 个 video_id 子文件夹、100 个 clip_id.mp4，全部参与特征提取，无增删。
- 附件 1 标注表 label-100.xlsx：提供 video_id、clip_id、text（英文转写）、label（连续情感强度）、
  annotation（情感极性文字标签）。
- 附件 2 的 aligned_50.pkl：作为特征维度与序列位置数的对照基准（文本 768 维、语音 74 维、
  视觉 35 维、统一 50 个序列位置），用于核对自生成特征与赛题特征在存储口径上的一致性。

## 三、核心假设

1. 每条视频片段的情感标注在片段内部恒定，即整段共享同一个连续情感强度与极性标签。
2. 片段的物理时间轴可以从容器时长可靠读出，且三模态共享同一条时间轴，不存在模态间的系统时钟偏移。
3. 在缺少逐词时间戳的条件下，语音与视觉的局部特征按时间比例映射到统一栅格，其时间分辨率误差
   不超过一个栅格宽度；该误差的来源与量级在结果解释中显式给出。
4. 文本按词元在句中的出现次序均匀分配到 50 个位置，作为文本通道的时序组织方式；该组织方式只影响
   文本特征的时间权重分布，不改变整句语义的完整性。位置 $k$ 覆盖词元区间
   $[\lfloor kT/L\rfloor,\lfloor (k+1)T/L\rfloor)$，区间为空时取相邻词元，因此文本通道 50 个位置全部有效。
5. 对极短片段不做丢弃或替换，只在有效长度记录中如实登记。

## 四、符号与变量

| 符号 | 含义 | 类型 |
|---|---|---|
| $n$ | 样本总数，附件 1 中 $n=100$ | 常量 |
| $L$ | 统一序列位置数，$L=50$ | 常量 |
| $D_i$ | 第 $i$ 条片段时长（秒） | 实测量 |
| $\tau_k$ | 第 $k$ 个序列位置代表时刻，$\tau_k=(k+0.5)D_i/L$ | 导出量 |
| $I_k$ | 第 $k$ 个位置对应时间区间 $[kD_i/L,(k+1)D_i/L)$ | 导出量 |
| $\mathbf{x}^{\mathrm{txt}}_k$ | 第 $k$ 个位置的文本特征向量，$\in\mathbb{R}^{768}$ | 导出量 |
| $\mathbf{x}^{\mathrm{aud}}_k$ | 第 $k$ 个位置的语音特征向量，$\in\mathbb{R}^{74}$ | 导出量 |
| $\mathbf{x}^{\mathrm{vis}}_k$ | 第 $k$ 个位置的视觉特征向量，$\in\mathbb{R}^{35}$ | 导出量 |
| $m^{\mathrm{mod}}_k$ | 第 $k$ 个位置的模态有效标志，有效为 1、填充为 0 | 导出量 |

## 五、公式与约束

**对齐映射。** 定义把物理时间 $t\in[0,D_i]$ 映射到栅格位置的时间量化算子

$$\kappa(t)=\min\Big(L-1,\ \Big\lfloor \frac{t\,L}{D_i}\Big\rfloor\Big),$$

区间 $I_k$ 是 $\kappa(t)=k$ 的原像。语音与视觉的局部特征对 $I_k$ 内所有帧取统计聚合：

$$\mathbf{x}^{\mathrm{aud}}_k=\Big[\ \operatorname{mean}_{j\in \mathcal{A}_k}\ell_j\ \Big\|\ \operatorname{std}_{j\in\mathcal{A}_k}\ell^{(1:8)}_j\ \Big\|\ \operatorname{mean}_{j\in\mathcal{A}_k} e_j\ \Big\|\ \operatorname{std}_{j\in\mathcal{A}_k} e_j\ \Big],$$

其中 $\ell_j$ 是第 $j$ 帧的 64 维对数梅尔谱、$e_j$ 是该帧均方根能量、$\mathcal{A}_k$ 是落入 $I_k$ 的帧集合。
视觉特征对同一区间内的解码帧取 HSV 统计量、色调熵与相邻帧灰度差统计。文本特征按词元次序分块后
做哈希词袋表示并逐位置 L2 归一化。

**有效长度与填充。** 有效标志满足

$$m^{\mathrm{mod}}_k=\mathbb{1}\big[\mathcal{A}^{\mathrm{mod}}_k\neq\varnothing\big],\qquad
\sum_{k=0}^{L-1} m^{\mathrm{mod}}_k=\text{有效位置数}\le L .$$

**约束条件。** 一是样本覆盖约束：100 条样本必须一一对应，任何样本不得被丢弃或替换；
二是时序可核验约束：位置代表时刻必须严格单调，$\tau_0<\tau_1<\cdots<\tau_{L-1}$，
且相邻间隔恒为 $D_i/L$；三是数值约束：输出特征不得含 NaN 或无穷值；四是维度约束：三模态特征维度
分别固定为 768、74、35，与赛题特征文件的存储口径一致。

## 六、方法

- 解复用与重采样：ffmpeg 把视频拆成 16 kHz 单声道 PCM 音频与 5 fps、112×112 的帧序列。
- 语音表示：librosa 计算 64 维对数梅尔谱与帧级均方根能量，按栅格区间聚合为 74 维。
- 视觉表示：OpenCV 计算 HSV 通道统计、色调/饱和度/亮度直方图、色调熵与帧间灰度差，按栅格聚合为 35 维。
- 文本表示：小写化与英文词元切分后，把词元与相邻二元组经 BLAKE2b 哈希映射到 768 维词袋，逐位置归一化。
- 对齐：以上述时间量化算子为唯一对齐规则，三模态共用同一条时间轴与同一个栅格。

候选方法比较：文本表示比较了哈希词袋、TF-IDF 加权词袋与外部预训练编码器三条路线。赛题允许使用
开源预训练模型，但本项目为满足“不引入外部数据集与外部预训练权重”的自设约束、并保证在任何机器上
可离线复现，选择哈希词袋路线；其代价是丢失上下文语义，该代价在模型局限中明确写出。

## 七、验证设计

1. 覆盖性核对：自生成特征文件的样本数、样本编号集合与 label-100.xlsx 完全一致。
2. 时序核对：逐样本比对栅格代表时刻的单调性与等间隔性，并核对音频特征中登记的片段时长与容器时长一致。
3. 数值核对：统计 NaN、无穷值与全零位置的分布，确认无异常。
4. 对齐效果核对：选取典型样本，把文本词元、语音时段、视频帧段与三类特征在同一时间轴上并列展示。
5. 口径核对：把自生成特征的维度与序列位置数与附件 2 的存储口径逐项对照。

## 八、输出文件

- `Q1/features_a1_100.npz`：100 条样本的三模态特征、有效标志、时长、标签与样本编号
- `Q1/特征提取全量汇总表.csv`：全量结果汇总表（样本编号、模态类型、原始有效时长、特征维度、对齐粒度等）
- `Q1/feature_config.json`：工具版本、关键参数、维度布局与随机种子
- `Q1/feature_audit.json`：覆盖性、数值与时长一致性核对结果
- `Q1/figures/`：本问生成图
- `Q1/result.md`：本问完整结果说明
