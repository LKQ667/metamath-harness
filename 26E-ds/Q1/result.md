# 问题一结果说明

## 问题目标

基于附件 1 的 100 条原始视频，建立文本、语音、视觉三模态情感特征提取与时序对齐的数学模型，
产出满足覆盖完整性、时序可核验性与可复现性三项要求的自生成特征文件，并用典型样本展示三模态在同一
时间轴上的对应关系。

## 输入数据

- 附件 1：`赛题/E题数据/E题数据/附件1-数据集原始多模态样本/MOSEI数据集部分原始视频-100条/`，
  37 个 video_id 子文件夹、100 个 clip_id.mp4 与标注表 `label-100.xlsx`。
- 附件 2 对齐版：`附件2-数据集特征文件/aligned_50.pkl`，用于核对特征维度与序列位置数的存储口径。

## 核心假设

1. 每条片段的情感标注在片段内部恒定。
2. 片段物理时间轴可由容器时长可靠读出，三模态共享同一条时间轴。
3. 缺少逐词时间戳时，语音与视觉的局部特征按时间比例映射到统一栅格，时间分辨率误差不超过一个栅格宽度。
4. 文本按词元出现次序等分到 50 个位置；位置 $k$ 覆盖词元区间
   $[\lfloor kT/L\rfloor,\lfloor (k+1)T/L\rfloor)$，区间为空时取相邻词元，因此文本 50 个位置全部有效。
5. 对极短片段不丢弃、不替换，只在有效长度记录中如实登记。

## 模型思路

处理链为：ffmpeg 解复用 → 音频重采样到 16 kHz 单声道、视频抽帧到 5 fps、112×112 → 三条模态支路各自
特征化 → 按时间量化算子 $\kappa(t)=\min(L-1,\lfloor tL/D_i\rfloor)$ 映射到 50 个等分区间 →
区间内统计聚合 → 输出特征矩阵与有效标志。语音支路用 librosa 计算 64 维对数梅尔谱与帧级均方根能量，
聚合成 74 维；视觉支路用 OpenCV 计算 HSV 统计、色调/饱和度/亮度直方图、色调熵与帧间灰度差，聚合成
35 维；文本支路把词元与相邻二元组经 BLAKE2b 哈希映射到 768 维词袋并逐位置 L2 归一化。

## 关键公式通俗解释

时间量化算子把片段时长 $D_i$ 等分成 50 份，落在第 $k$ 份里的所有帧归入位置 $k$；位置代表时刻取该份的
中点 $(k+0.5)D_i/50$。有效标志只在区间内确实取到帧时为 1，因此短片段会出现无帧位置，这些位置按填充位
如实登记而不是插值补齐。全部参数、工具版本与随机种子记录在 `feature_config.json`。

## 运行命令

```bash
python Q1/extract_features.py
```

## 结果解释

100 条样本全部完成特征提取，无缺失、无异常数值，三模态维度与序列位置数与附件 2 的存储口径一致，
说明自生成特征可以直接接入问题二与问题三的模型接口。语音通道平均 49.69 个位置有效，几乎覆盖全部栅格；
视觉通道平均只有 33.97 个位置有效，最少 0 个、最多 48 个，原因是 5 fps 抽帧在极短片段上覆盖不足，
这一现象说明“局部时段视觉信息不可用”在真实数据里天然存在，而不是人为构造。对齐粒度随时长从 0.0451 秒
变到 0.5858 秒，长片段的单栅格时间分辨率更低，是本文对齐规则的主要误差来源。视觉特征空间的三维投影显示
三个情感类别的类心高度重叠，说明情感判别不能依赖全局均值特征，必须使用时序编码。

## 局限与下一问衔接

本问的局限有三点：一是文本使用哈希词袋表示，丢失上下文语义，且未使用任何预训练权重；二是语音与视觉
特征为声学与图像统计量，不是情感专用表示；三是缺少逐词时间戳，文本位置只表示词元出现次序而非真实发音
时刻。下一问在这些特征上建立缺失感知的鲁棒预测模型，缺失掩码的反演规则直接沿用本问的有效标志定义。
